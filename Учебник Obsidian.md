# Учебник Obsidian — полный мануал

**Obsidian** — программа для ведения базы знаний (второго мозга) на базе локальных Markdown-файлов. Главная идея — каждая заметка это обычный `.md`-файл в папке на диске, а связи между заметками строятся через внутренние ссылки `[[...]]`. Под капотом — просто файлы в папках, никакой магии. Бесплатна для личного использования, работает на Windows, macOS и Linux.

## Зачем Obsidian

Obsidian — это «*A second brain, for you, forever*». Его сильные стороны:

- **Похож на VScode**: слева древо файлов, справа оглавление
- **Плагины** — огромная экосистема (все плагины опенсорсные)
- **Шорткаты** — быстрая работа с клавиатуры
- **Рендер Markdown** прямо во время редактирования
- **Версии для ПК и Android** — идентичные интерфейсы
- **Под капотом обычные `.md`-файлы** — переносимость без привязки к софту
- **Переименование и перемещение** заметок автоматически обновляет все ссылки на них

### Наблюдать ли на Obsidian рассчитывать

Obsidian лучше всего работает как **wiki-заметки для себя**. Программа подойдёт, если:

- заметки ведутся для себя
- нет желания устанавливать и настраивать wiki-движки
- Markdown-разметка для вас новая
- не требуется сложный экспорт в другие форматы

Порог вхождения минимальный даже для людей не из IT.

### Obsidian vs другие инструменты

| Инструмент | Назначение | Лучшие стороны | Ограничения |
|---|---|---|---|
| **Obsidian** | личная база знаний | сети заметок `[[...]]`, плагины, граф | закрытые фичи в Obsidian Sync/Publish |
| **Joplin** | менеджер заметок | шифрование, заметки в Markdown | нет графа связей |
| **Тypora** | редактор Markdown | WYSIWYG, удобные таблицы | не база знаний |

## Быстрый старт

### Создание хранилища (vault)

**Vault (хранилище)** — просто папка на диске, куда складываются Markdown-заметки, изображения, PDF и другие файлы. Всё нужное перетаскивается в окно программы и попадает в эту папку.

1. Установите Obsidian (Linux: `sudo apt install obsidian` или из AUR `obsidian`)
2. Запустите и выберите **Create new vault** — укажите название и папку
3. Внутри появится файл `.obsidian/` с настройками и папка с заметками

### Первая заметка

Создайте заметку (`Ctrl+N`). Определите **точку входа** — README-файл с оглавлением хранилища и ссылками на основные темы.

```
В этой базе собраны знания о том, что есть [[квантовая точка]]
```

Внутренняя ссылка `[[квантовая точка]]` — пока не существует файла с таким именем, ссылка «висячая». Один клик по ней создаст новую заметку.

## Ядро Obsidian: ссылки и встраивание

На трёх китах основывается вся магия Obsidian:

```markdown
%% Внутренняя ссылка %%
[[README]]

%% Внешняя ссылка %%
[README](https://github.com/example/readme)

%% Встраивание документа %%
![README](README.md)
```

- **Внутренние ссылки** `[[Заметка]]` — связь между страницами базы. Можно ссылаться на заголовок `[[Заметка#Заголовок]]`
- **Внешние ссылки** — обычный Markdown `[текст](url)`
- **Встраивание (embedding)** `![[Заметка]]` — вставка содержимого заметки внутрь другой. Killer feature Obsidian
- **Backlinks** — панель, показывающая, с каких страниц есть ссылки на текущую

### Шаблоны ссылок

Для совместимости с GitHub и другими программами рекомендуется:
- **Формат новой ссылки**: относительный путь к файлу
- **Использовать Wiki-ссылки**: false
- Использовать обычные ссылки `[text](link)` вместо `[[link]]`

Уже существующие wiki-ссылки можно конвертировать (плагин Consistent attachments and links).

## Методология: Zettelkasten

Obsidian идеально подходит для техники **Zettelkasten** (метод картотек немецкого социолога Никласа Лумана — он написал более 70 книг и 400 статей).

**Советы:**
- Пишите **краткие заметки** (атомарность изложения важна)
- Переходите от темы к теме, выстраивайте связи
- Пускай логическая нестройность не беспокоит — всегда можно поправить потом
- Каждая заметка становится «нейроном» вашей сети знаний, обрастает «синапсами» (ссылками)
- Со временем сеть связей превращается в личного ассистента, который сам подсказывает неочевидные пересечения тем

## Продвинутый поиск

Поле поиска (Ctrl+Shift+F) имеет богатый функционал:

- `/hello.*world/` — поиск по RegExp между `/ /`
- `path:FolderName` — поиск только в определённой папке
- `/Shift.*Enter/` — поиск фразы с вариациями (Shift+Enter, Shift + Enter и т.д.)
- `/forward.?vector/` — найдёт "forwardvector", "forward vector", "forward-vector"
- `/Shift\+Enter/` — экранирование спецсимволов

Результаты поиска можно **вставлять прямо в заметку** (встроенный плагин Search / Embed search).

## Синхронизация

### Вариант 1: Git (рекомендуется)

Плагин **Obsidian Git** — push/pull из git, автобэкап. Хоткеи:
- `Ctrl+Alt+S` — commit and push
- `Ctrl+Alt+L` — pull

Плюсы: история версий, мержинг, работа через любой git-хостинг (GitHub, GitLab).

### Вариант 2: Syncthing (Linux)

**Syncthing** — peer-to-peer синхронизация без облака. Ставится на оба устройства, файлы синхронизируются напрямую.

```bash
systemctl enable syncthing@$USER.service
systemctl start syncthing@$USER.service
```

Плюсы: бесплатно, без облака, работает на любых файлах.
Минусы: оба устройства должны быть онлайн; при конфликтах версий появляются файлы `*.sync-conflict-*`, которые нужно резолвить вручную.

### Вариант 3: WebDAV (облако mail.ru)

1. Создайте пароль для приложения на https://account.mail.ru/user/2-step-auth/passwords/
2. Установите плагин **Remotely Save**
3. В настройках: адрес `https://webdav.cloud.mail.ru`, полная почта, пароль приложения
4. Настройте папку, шифрование, частоту синхронизации
5. Повторите на мобильном (настройки можно передать через QR-код)

При ошибке конфликта файлов более 50%, поставьте параметр **Above Sync If Modification Above Percentage = 100**.

## Уборка и обслуживание

### Чистка неиспользуемых файлов

Плагин **Find unlinked files**:
- В настройках укажите игнорировать `.md`-файлы
- Команда «список незалинкованных файлов» и «список битых ссылок»
- Команда удаления всех неиспользуемых файлов с указанным расширением

### Организация отдельной темы

Удобно создать страницу-карту со ссылками на все заметки темы и закрепить её на левой панели. В отличие от списка файлов, тут можно рассортировать заметки в нужной последовательности и добавить оформление.

## Интеграция с другими программами

### Typora / Marktext

Эти редакторы дают удобные таблицы и WYSIWYG. Для максимальной совместимости: **отключите wiki-ссылки** и **включите относительные пути**. Typora можно сделать дефолтным редактором `.md`, а из Obsidian открывать его по хоткею **Open in default app**.

### VSCode

Плагины для ведения заметок в VSCode:
- **Markdown Memo** — ссылки между страницами и изображения (без ссылок на заголовки)
- **Foam for VSCode** — как Obsidian в эдиторе
- **Markdown All In One** — помощь с разметкой

Включите опцию `Markdown > Preview: Breaks`, чтобы перенос строк работал как в Obsidian.

## Ограничения и особенности

- **Умный поиск путей** — Obsidian ищет ссылки на вложения по имени, даже если папки нет на месте. Плюс (сложнее сломать ссылки), минус (GitHub и другие программы не поддерживают это — ссылка окажется битой)
- **Как узнать реальный путь**: в режиме редактирования ПКМ по ссылке → *Reveal file in navigation*
- **Экспорт в PDF** работает, но для сложных документов надёжнее сначала привести к стандартному Markdown
- Все настройки и плагины хранятся в папке `.obsidian/` внутри vault — бекапится вместе с заметками
