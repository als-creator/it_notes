## Что такое PHP и зачем он нужен

PHP (от *PHP: Hypertext Preprocessor*) — язык для написания **серверных** веб-приложений. Скрипт выполняется на сервере, а результат чаще всего — HTML-страница, которую отдаёт браузер. Код PHP не виден пользователю: он отрабатывает «за кулисами».

Почему PHP популярен среди новичков:

- низкий порог входа — первая программа занимает одну строку;
- огромное количество готовых приложений и CMS (WordPress, Laravel, Symfony, Bitrix);
- встроенная поддержка работы с веб-запросами, формами, куки, сессиями, JSON;
- богатая стандартная библиотека функций (строки, массивы, даты, файлы);
- быстрый запуск: один файл `.php` — и уже работает сайт.

PHP — **интерпретируемый** язык: код транслируется в опкод и выполняется при каждом запуске без отдельной компиляции в машинный код.

### Схема: путь запроса через PHP

```
+----------+     HTTP-запрос (GET/POST)     +----------------+
| БРАУЗЕР  | -----------------------------> | ВЕБ-СЕРВЕР     |
| (клиент) |                                | (Apache/Nginx) |
+----------+                                +----------------+
      ^                                              |
      |   HTTP-ответ:                              |  сервер видит ".php" в URL
      |   HTML + данные                            v
      |                                   +----------------+
      |                                   | PHP-интерпретатор |
      |                                   | - разбирает код  |
      |                                   | - выполняет код  |
      |                                   | - отдаёт результат|
      +---------------------------------- +----------------+
```

Браузер отправляет запрос к URL вида `https://site.ru/index.php?page=about`. Веб-сервер видит расширение `.php`, запускает интерпретатор PHP, который исполняет скрипт. Всё, что скрипт «вывел» (чаще всего HTML), сервер возвращает браузеру.

### Попробуй сам

Позже, в разделе «Установка PHP», вы запустите свой первый скрипт. Пока просто прочитайте программу — вот почти вся она:

```php
<?php
echo "Привет, мир!";
```

## Как PHP обрабатывает запрос

PHP может быть подключён к веб-серверу двумя основными способами.

### Схема 1: модуль (Apache + mod_php)

PHP «встроен» прямо в процесс веб-сервера:

```
+-----------------------------------------------------------+
|                    APACHE (один процесс)                   |
|                                                           |
|   mod_php  |  mod_rewrite  |  статические файлы  |  ...   |
|            |                                          встроенный
|   PHP-код исполняется внутри самого сервера            интерпретатор
+-----------------------------------------------------------+
```

**Плюсы:** простая настройка. **Минусы:** каждый воркер Apache несёт в себе PHP, память расходуется даже на раздачу картинок.

### Схема 2: PHP-FPM (отдельный менеджер процессов)

PHP работает отдельным сервисом. Nginx или Apache передают ему запросы через FastCGI:

```
                 FastCGI                          FastCGI
+--------+    ---------------->    +------------------------------+
| Nginx  |  --->  PHP-FPM master   |  пул воркеров (worker-процессы) |
| (front)|  <-------------------  |  каждый воркер исполняет PHP  |
+--------+      ответ             +------------------------------+
```

Это современный стандарт: разделение процессов, гибкая настройка производительности, возможность держать несколько версий PHP.

### Схема 3: встроенный сервер для разработки

`php -S localhost:8000` поднимает одно-процессный сервер только для локальной разработки и тестов.

### Попробуй сам

Установите PHP (см. следующий раздел), затем выполните:

```bash
cd ~/projects/hello
php -S localhost:8000
```

Откройте `http://localhost:8000/index.php` — встроенный сервер запустит скрипт.

## HTML внутри PHP и наоборот

PHP-файл — это по сути HTML-шаблон с вкраплениями кода. Всё, что вне тегов `<?php ... ?>`, выводится как есть.

### Схема: что выводится, а что выполняется

```
+--------------------------------------------------------------+
| index.php (обычный текст + вкрапления PHP)                   |
|                                                              |
|   <h1>Привет</h1>          <- выводится "как есть"           |
|   <?php echo $name; ?>     <- выполняется, результат вставляется|
|   <p>Текст</p>             <- выводится "как есть"           |
+--------------------------------------------------------------+
| результат для браузера: "Привет" + имя + "Текст"             |
+--------------------------------------------------------------+
```

### Пример «PHP внутри HTML»

```php
<?php $name = "Мария"; ?>
<!DOCTYPE html>
<html>
<body>
    <h1>Привет, <?= $name ?>!</h1>
</body>
</html>
```

Запись `<?= ... ?>` — короткая форма `<?php echo ... ?>`. Она работает всегда (независимо от `short_open_tag`).

### Пример «HTML внутри PHP»

```php
<?php
if (isset($_GET['user'])) {
    // HTML внутри условия
    echo "<h1>Пользователь: " . htmlspecialchars($_GET['user']) . "</h1>";
}
```

### Попробуй сам

Создайте `page.php` с переменной `$title` и выведите её в теге `<title>` через `<?= $title ?>`.

## Переменные и типы данных

Переменная в PHP всегда начинается с `$`. Тип указывать не нужно — PHP сам определит его по значению.

### Схема типов данных

```
                        PHP: типы данных
                                |
        +-----------------------+---------------------+
        |                        |                     |
      СКАЛЯРНЫЕ               СОСТАВНЫЕ             СПЕЦИАЛЬНЫЕ
   (одно значение)          (много значений)        (частные случаи)
        |                        |                     |
   +----+-----+--+        +-----+-----+            +--+--+
   |          |  |        |           |            |     |
  int  float  string bool  array  object       null   resource
 (целые) (дробные)(строки)(логика) (код  ) (массив)(объект) (нет значения)
```

### Основные типы

```php
<?php
$age       = 25;        // int
$price     = 19.99;     // float
$name      = "Ольга";   // string (двойные кавычки)
$city      = 'Москва';  // string (одинарные кавычки)
$is_active = true;      // bool

var_dump($age, $price, $name, $is_active);
```

Важные нюансы:

- **Двойные кавычки** подставляют переменные и escape-последовательности: `"Привет, $name!"` → `Привет, Ольга!`; **одинарные** — нет: `'Привет, $name!'` останется как есть.
- Ведущие нули в числах теряются: `$code = 007;` → `7`.
- Строковое число при арифметике PHP преобразует автоматически («жонглирование типами»): `"5" + 2` → `7`.

### Попробуй сам

```bash
php -r '$x = 3; $y = "4"; echo $x + $y; echo " "; echo $x . $y;'
```

Обратите внимание: `+` складывает числа, а `.` — конкатенация строк.

## Вывод данных: echo, print, var_dump

| Конструкция | Что делает |
|---|---|
| `echo "текст", "ещё"` | выводит сразу несколько значений, быстрее всего |
| `print "текст"` | выводит одно значение, возвращает `1` |
| `var_dump($x)` | выводит тип и значение — незаменимо при отладке |
| `print_r($x)` | человекочитаемый вывод массивов и объектов |

### Схема вывода

```
    PHP-код                     Экран / HTTP-ответ
"Привет"  ----------> echo ---------->  Привет
["a","b"] ----------> print_r ------->  Array ( [0] => a [1] => b )
42.5      ----------> var_dump ------>  float(42.5)
```

### Попробуй сам

```php
<?php
echo "echo без скобок";
echo("echo в скобках тоже можно");
print "print возвращает 1";
var_dump([1, 2, 3]);
```

### Задание

Выведите массив `[10, "десять", 10.5]` всеми тремя способами (`echo`, `print_r`, `var_dump`) и сравните разницу в выводе.

### Самопроверка

**Ответ:**

`echo` просто склеит значения в строку. `print_r` покажет индексы и значения в читаемом виде. `var_dump` дополнительно укажет типы (`int`, `string` с длиной, `float`).

## Константы

Константу определяют один раз через `define()`, в классах — через `const`. Значение изменить нельзя.

### Классические константы

```php
<?php
define("APP_NAME", "Мой блог");
define("MAX_ITEMS", 10);

echo APP_NAME;     // без $
echo constant("MAX_ITEMS");
```

### Константы через const и магические

```php
<?php
const VERSION = "1.0.0";

echo __FILE__;   // путь к текущему файлу
echo __LINE__;   // номер текущей строки
echo __DIR__;    // каталог текущего файла
echo PHP_VERSION; // версия PHP
```

## Операторы

### Арифметика и присваивание

```php
<?php
$a = 10;
$b = 3;

$x = $a + $b;  // 13
$y = $a - $b;  // 7
$z = $a * $b;  // 30
$q = $a / $b;  // 3.333...
$r = $a % $b;  // 1 (остаток)
$p = $a ** $b; // 1000 (степень)
```

Сокращённые формы: `$a += 5;` (прибавить), `$a -= 5;`, `$a *= 2;`, `$a .= " str"` (конкатенация). Инкремент/декремент: `$a++`, `++$a`, `$a--`, `--$a`.

### Сравнение и логика

```php
<?php
$a = 5;
$b = "5";

var_dump($a == $b);   // true  (сравнение значений, типы неважны)
var_dump($a === $b);  // false (строгое сравнение по значению И типу)
var_dump($a != $b);   // false
var_dump($a !== $b);  // true
var_dump($a <=> $b);  // 0  (космический корабль: -1 / 0 / 1)

var_dump($a > 3 && $b < 10);   // true (И)
var_dump($a < 3 || $b > 2);    // true (ИЛИ)
var_dump(!$a);                 // false (отрицание)
```

### Null-операторы (золото современного PHP)

```php
<?php
$name = $_GET['name'] ?? "Гость"; // ??: если нет или null — замена

$user = null;
$nick = $user?->nickname;        // ?->: nullsafe-доступ, не упадёт
```

### Попробуй сам

```bash
php -r 'var_dump(10 / 3); var_dump(10 % 3); var_dump("10" == 10, "10" === 10);'
```

## Условия: if, else, switch и match

### Классические if/elseif/else

```php
<?php
$score = 75;

if ($score >= 90) {
    echo "Отлично";
} elseif ($score >= 60) {
    echo "Хорошо";
} else {
    echo "Старайся больше";
}
```

### switch

```php
<?php
$day = 3;

switch ($day) {
    case 1:
        echo "Понедельник";
        break;
    case 2:
        echo "Вторник";
        break;
    default:
        echo "Просто день";
}
```

`switch` использует нестрогое сравнение (`==`) и требует `break`.

### match — строгий и возвращает значение

Появился в PHP 8, идеален как выражение:

```php
<?php
$status = 404;

$message = match ($status) {
    200 => "OK",
    404 => "Not Found",
    500 => "Server Error",
    default => "Unknown",
};

echo $message; // Not Found
```

Особенности `match`: строгое сравнение (`===`), не требует `break` (каждое условие завершается), каждый вложенный `=>` — отдельная ветка, всегда что-то возвращает.

### Схема выбора

```
                   $status = 404
                        |
      +-----------------+-------------------+
      |                match                |
100->"OK"    404->"Not Found"  500->"Server Error"
      |                  |                  |
      +------------------+------------------+
                       вывод: "Not Found"
```

### Попробуй сам

```bash
php -r '$n=2; $r = match($n){1=>"one",2=>"two",default=>"many"}; echo $r;'
```

### Задание

Напишите фрагмент, который по коду страны (`"ru"`, `"en"`, `"de"`) через `match` возвращает название языка (русский, английский, немецкий). Добавьте `default => "другой язык"`.

### Самопроверка

**Ответ:**

```php

    "ru" => "русский",
    "en" => "английский",
    "de" => "немецкий",
    default => "другой язык",
};
echo $lang;
```

## Циклы: for, foreach, while

### for — когда известно количество итераций

```php
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "$i ";
}
// 1 2 3 4 5
```

### while и do-while

```php
<?php
$stock = 3;
while ($stock > 0) {
    echo "Осталось товаров: $stock\n";
    $stock--;
}

do {
    echo "Выполнено хотя бы раз\n";
} while (false);
```

### foreach — обход массивов (самый частый цикл)

```php
<?php
$users = ["Иван", "Мария"];
foreach ($users as $name) {
    echo "$name\n";
}

// с индексами
$cart = ["яблоки" => 2, "хлеб" => 1];
foreach ($cart as $item => $count) {
    echo "$item × $count\n";
}
```

### Управление: break и continue

```php
<?php
for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 === 0) {
        continue; // чётные пропускаем
    }
    if ($i >= 7) {
        break;    // на 7 останавливаемся
    }
    echo "$i ";
}
// 1 3 5
```

### Схема for vs foreach

```
for:   $i=1 ------> условие $i<=5 ----> тело ----> $i++ ----> снова условие

        \ ситачей: неважны индексы, важны сами значения
```

### Попробуй сам

## Строки и строковые функции

Строки создаются одинарными или двойными кавычками. Для сложных вставок используйте heredoc и nowdoc.

```php
<?php
$json = <<<JSON
{"site": "example.com"}
JSON;

EOT;
```

### Полезные функции

```php
<?php
$s = "  Привет, мир!  ";

strlen($s);        // длина строки (в байтах)
mb_strlen($s);     // длина в символах (кириллица!)
trim($s);          // удалить пробелы с краёв
strtoupper($s);    // "ПРИВЕТ, МИР!"
mb_strtolower($s); // "привет, мир!" для кириллицы
str_replace("мир", "PHP", $s); // замена подстроки
substr("Hello world", 6, 3);  // "wor" (по байтам)

str_starts_with($s, "Привет"); // true
str_ends_with($s, "!");      // true
implode("+", ["a","b"]);     // "a+b"
```

Важно: функции без приставки `mb_` считают **байты**, поэтому с русским текстом всегда используйте `mb_*`-варианты.

## Массивы и функции массивов

Массив — упорядоченная структура «ключ → значение».

### Три вида массивов

```php
<?php
// Индексный (ключи 0,1,2...)
$fruits = ["яблоко", "груша", "слива"];

// Ассоциативный (строковые ключи)
$user = ["name" => "Ольга", "age" => 30];

// Многомерный (массив массивов)

    [1, 2, 3],
    [4, 5, 6],

```

### Схема ассоциативного массива

```
        +------+---------+
$user:  | name | Ольга   |
        +------+---------+
        | age  | 30      |
        +------+---------+
```

### Основные операции

```php
<?php
$arr = [3, 1, 2];

count($arr);              // 3
array_push($arr, 4);      // добавить в конец
sort($arr);               // по возрастанию (индексные)
array_key_exists("age", $user); // true
in_array("груша", $fruits);     // true — есть ли значение

```

### Функции высшего порядка (PHP-стиль функциональный)

```php
<?php
$prices = [100, 250, 400];

$withTax = array_map(fn($p) => $p * 1.2, $prices);   // [120, 300, 480]
$expensive = array_filter($prices, fn($p) => $p > 200); // [250, 400]

$str = implode(", ", $prices);   // "100, 250, 400"
$back = explode(", ", $str);     // обратно в массив
```

`array_map` применяет функцию к каждому элементу, `array_filter` оставляет элементы по условию, `implode`/`explode` склеивают/разбивают строку, `in_array` проверяет вхождение.

## Функции: именованные, анонимные, стрелочные

### Именованная функция + типы + возврат

```php
<?php
function sum(int $a, int $b): int
{
    return $a + $b;
}

echo sum(2, 3); // 5
```

Типы параметров (`int $a`) и тип возврата (`: int`) задаются с PHP 7 и активно используются в 8.x.

### Аргументы со значением по умолчанию и вариативные

```php
<?php
function greet(string $name, string $greeting = "Привет"): string
{
    return "$greeting, $name!";
}

greet("Оля");                  // "Привет, Оля!"
greet("Оля", "Здравствуй");    // "Здравствуй, Оля!"

function total(...$numbers): int
{
    return array_sum($numbers);
}
total(1, 2, 3, 4); // 10
```

### Named arguments (именованные аргументы, PHP 8)

```php
<?php
greet(greeting: "Salut", name: "Оля");  // порядок неважен!
```

Это удобно читается и устойчиво к изменению порядка параметров.

### Анонимная и стрелочная

```php
<?php
$square = function ($x) {
    return $x * $x;
};

// стрелочная — короткая запись, `use` не нужен
$cube = fn($x) => $x ** 3;

echo $square(4), " ", $cube(3); // 16 27
```

Стрелочные функции автоматически захватывают переменные из внешней области; в анонимных нужен `use ($var)`.

### Схема: именованная vs анонимная vs стрелочная

```
именованная:  function имя(...) { ... }   — вызываем по имени много раз
анонимная:    $f = function(...) { ... }; — хранится в переменной
стрелочная:   $f = fn(...) => выражение;  — одна строка, неявный return
```

### Попробуй сам

```bash
php -r 'function f(int $a, int $b = 1): int { return $a * $b; } echo f(5);'
php -r 'echo f(a: 4, b: 8);'
```

Напишите функцию `fizzbuzz(int $n): string`, которая для числа кратного 3 возвращает `Fizz`, кратного 5 — `Buzz`, и обоим — `FizzBuzz`, иначе само число. Покройте числа 15, 5, 2.

### Самопроверка

```php

        [true, true]  => "FizzBuzz",
        [true, false] => "Fizz",

```

## Формы и обработка запросов GET и POST

Форма отправляется на PHP-скрипт; данные попадают в `$_GET` или `$_POST`.

### Схема GET vs POST

```
GET  (url: /search.php?q=php&page=2)
  + параметры ВИДНЫ в адресной строке
  + кэшируются, можно добавить в закладки
  - маленький объём (~2 КБ), данные в логах
  ЖИЗНЕННЫЙ ПРИМЕР: поиск, фильтры

POST (тело запроса)
  + параметры НЕ видны в URL (но видны в devtools)
  + почти без ограничений по объёму
  - не кэшируется, кнопка «назад» переспросит
  ЖИЗНЕННЫЙ ПРИМЕР: отправка формы, логин, загрузка файла
```

### Форма (HTML) + обработчик (index.php)

```php
<?php
$name = $_POST['name'] ?? '';
?>
<form method="post">
    <input type="text" name="name" value="<?= $name ?>">
    <button type="submit">Отправить</button>
</form>

<?php if ($_SERVER['REQUEST_METHOD'] === 'POST'): ?>
    <p>Привет, <?= htmlspecialchars($name) ?>!</p>
<?php endif; ?>
```

## JSON: json_encode и json_decode

JSON — основной формат обмена данными между фронтендом и бэкендом и между сервисами.

```php
<?php
$user = [
    "id" => 1,
    "name" => "Ольга",
    "tags" => ["php", "bash"],
];

$json = json_encode($user, JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT);
echo $json;

$back = json_decode($json, true); // true → ассоциативный массив
// без true — объект stdClass

json_decode("не валидный json", true); // null
json_last_error_msg();                 // сообщение об ошибке
```

### Схема json_encode / json_decode

```
массив PHP  ---json_encode-->  строка JSON  ---json_decode-->  массив PHP
[ "name" => ]   (сериализация)   {"name":..}   (десериализация)  [ "name" => ]
```

`JSON_UNESCAPED_UNICODE` оставляет кириллицу как есть (иначе — `\u043e...\u043b`).

## Работа с базами данных: PDO

PDO (PHP Data Objects) — единый интерфейс к разным СУБД (SQLite, MySQL, PostgreSQL). Ключевая практика — **prepared statements**: данные передаются отдельно от SQL-запроса, что закрывает SQL-инъекции.

### Схема SQL-инъекции и защиты

```
ВОПЛОЩЕНИЕ ИНЪЕКЦИИ:
  "SELECT * FROM users WHERE name = '" . $_GET['name'] . "'"
  пользователь вводит:  ' OR '1'='1
  результат SQL:        WHERE name = '' OR '1'='1'        <- вернёт ВСЕХ

ЗАЩИТА (prepared statement):
  SQL: "SELECT * FROM users WHERE name = ?"
  параметр: ' OR '1'='1   -> интерпретируется ТОЛЬКО как строка данных,
                              а не часть запроса
```

### SQLite через PDO — подходит для учебных проектов

```php
<?php
$pdo = new PDO("sqlite:/tmp/shop.db");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE IF NOT EXISTS products (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    price REAL NOT NULL
)");

// вставка (prepared statement с именованным параметром)
$stmt = $pdo->prepare("INSERT INTO products (name, price) VALUES (:name, :price)");
$stmt->execute([":name" => "Хлеб", ":price" => 45]);

// выборка
$rows = $pdo->query("SELECT * FROM products")->fetchAll(PDO::FETCH_ASSOC);

// безопасный поиск по пользовательскому вводу
$q = "%{$_GET['q']}%";
$stmt = $pdo->prepare("SELECT * FROM products WHERE name LIKE ?");
$stmt->execute([$q]);
$found = $stmt->fetchAll();
```

### MySQL через PDO

```php
<?php
$pdo = new PDO(
    "mysql:host=localhost;dbname=shop;charset=utf8mb4",
    "user",
    "secret",
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);
```

### Главное правило

Любой пользовательский ввод идёт через `prepare` + `execute` с плейсхолдерами (`?` или `:name`) — никогда не конкатенируйте данные в SQL-строку.

## Сессии и куки

Сессии и куки нужны, чтобы «помнить» пользователя между запросами.

### Схема сессии

```
ЗАПРОС №1                                ЗАПРОС №2
  POST login.php                          GET /account.php
  +----------------+                      +----------------+
  | session_start()|                      | session_start()|
  | $_SESSION=...  |  браузер хранит      | $_SESSION уже  |
  | создан          |  cookie PHPSESSID    | восстановлен  |
  | файл сессии    |══════════════════════=>               |
  +----------------+                      +----------------+
   сервер хранит данные                  роль играет кука-ID
```

### Код

```php
<?php
session_start();

// сохранить на сервере (данные не видны клиенту)
$_SESSION['user_id'] = 42;
$_SESSION['cart'] = [1, 2, 3];

// проверить вход
if (isset($_SESSION['user_id'])) {
    echo "Пользователь вошёл";
}

session_destroy(); // выход: удалить сессию
```

### Куки — данные на стороне браузера

```php
<?php
setcookie("theme", "dark", time() + 3600, "/");
// параметры: имя, значение, срок действия, путь

echo $_COOKIE['theme'] ?? "Светлая тема";
```

Куку можно установить **до** любого вывода, иначе — ошибка «headers already sent».

### Попробуй сам

Два скрипта: `login.php` (`session_start(); $_SESSION['login']='admin';`) и `whoami.php` (пишет `$_SESSION['login']`). Перейдите в браузер последовательно.

## Безопасность: базовые практики

Для учебных проектов важно освоить четыре приёма — они закрывают основные дыры.

### 1. Вывод: htmlspecialchars

Всегда экранируйте данные пользователя при выводе в HTML:

```php
<?php
echo htmlspecialchars($_POST['comment'], ENT_QUOTES, 'UTF-8');
// теги <script> не исполнятся — XSS закрыт
```

### 2. Хранилище паролей: password_hash / password_verify

```php
<?php
$hash = password_hash("секрет", PASSWORD_DEFAULT);
// пароль НИКОГДА не хранится открытым текстом!

var_dump(password_verify("секрет", $hash)); // true
var_dump(password_verify("угадали?", $hash)); // false
```

`password_hash` сам генерирует случайную «соль». Сравнение — только через `password_verify`.

### 3. Валидация: filter_var

```php
<?php
$email = "user@example.com";
$ok = filter_var($email, FILTER_VALIDATE_EMAIL); // строка или false

$id = filter_input(INPUT_GET, "id", FILTER_VALIDATE_INT);
if ($id === false || $id === null) {
    die("Некорректный id");
}
```

### 4. База данных: prepared statements (раздел выше)

### Попробуй сам

```bash
php -r 'echo htmlspecialchars("<b>x</b>"); echo "\n"; echo password_verify("x", password_hash("x", PASSWORD_DEFAULT)) ? "ok" : "no";'
```

### Задание

Форма регистрации: получите `email` и `password`. Проверьте email через `filter_var`, пароль сохраните через `password_hash` (в текстовый файл строкой вида `email|hash` для простоты).

### Самопроверка

**Ответ:**

```php
<?php

$pass  = $_POST['password'] ?? "";

if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    die("Некорректный email");
}
if (strlen($pass) < 8) {
    die("Слишком короткий пароль");
}

$hash = password_hash($pass, PASSWORD_DEFAULT);
file_put_contents("users.txt", $email . "|" . $hash . PHP_EOL, FILE_APPEND);
echo "Готово";
```

## Composer и автозагрузка

[Composer](https://getcomposer.org) — менеджер зависимостей PHP: устанавливает библиотеки из Packagist и управляет автозагрузкой классов.

```bash
composer require vlucas/phpdotenv     # библиотека .env-файлов
composer require --dev phpunit/phpunit # зависмость только для разработки
```

После установки в проекте появляется файл `composer.json` и папка `vendor/`. Механизм автозагрузки:

```json
{
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    }
}
```

```bash
composer dump-autoload
```

Теперь класс `App\Service\UserService` автоматически подгрузится из файла `src/Service/UserService.php` — достаточно:

```php
<?php
require "vendor/autoload.php";

use App\Service\UserService;

$service = new UserService();
```

### Схема автозагрузки PSR-4

```
Запрос класса App\Service\UserService
        |
        v
vendor/autoload.php --> Composer ищет по префиксу "App\\" -> "src/"
        |
        v
src/Service/UserService.php  (загружается, создаём объект)
```

## ООП: классы и наследование

Класс — чертёж, объект — его экземпляр. Современный PHP 8 делает ООП компактным.

```php
<?php
class Vehicle
{
    public function __construct(
        protected string $brand,
        protected int $speed = 0
    ) {}

    public function speed(): int
    {
        return $this->speed;
    }

    public function accelerate(int $delta): void
    {
        $this->speed += $delta;
    }
}

// наследование
class Car extends Vehicle
{
    public function __construct(string $brand)
    {
        parent::__construct($brand, 60);
    }
}

$car = new Car("Toyota");
$car->accelerate(30);
echo $car->speed(); // 90
```

Ключевые возможности PHP 8, которые вы только что увидели:

- **constructor property promotion** — параметры `protected string $brand` сразу создают свойства;
- **typed properties** — `public int $speed`;
- модификаторы `public` / `protected` / `private`;
- `readonly` для неизменяемых свойств: `public readonly int $id`.

### Атрибуты (PHP 8)

Метаданные прямо в коде, читаются через Reflection:

```php
<?php
#[Attribute]
class Route
{
    public function __construct(public string $path) {}
}

#[Route("/users")]
class UsersController {}
```

Так устроены современные фреймворки (Symfony, Laravel): атрибуты заменяют конфиг-файлы маршрутов.

### Попробуй сам

```bash
php -r 'class A { public function __construct(public int $x) {} } $a=new A(5); echo $a->x;'
```

### Задание

Создайте класс `Counter` со свойством `count`, методами `increment()`, `decrement()`, `value(): int` и унаследуйте от него `AdvancedCounter`, добавив метод `reset()`.

### Самопроверка

**Ответ:**

```php
<?php
class Counter
{
    public function __construct(protected int $count = 0) {}
    public function increment(): void { $this->count++; }
    public function decrement(): void { $this->count--; }
    public function value(): int { return $this->count; }
}

class AdvancedCounter extends Counter
{
    public function reset(): void { $this->count = 0; }
}

$c = new AdvancedCounter();
$c->increment(); $c->increment();
echo $c->value(); // 2
$c->reset();
echo $c->value(); // 0
```

## PSR-стандарты

PSR (PHP Standard Recommendations) — рекомендации сообщества PHP-FIG. Стандартный код легко читается любым разработчиком.

| Стандарт | Про что |
|---|---|
| **PSR-1** | базовые правила стиля: классы — `StudlyCase`, методы — `camelCase` |
| **PSR-4** | автозагрузка: namespace ↔ пути на диске |
| **PSR-12** | расширенный стиль кода: отступы 4 пробела, фигурные скобки на новой строке |
| **PSR-7** | интерфейсы HTTP-запросов/ответов (основа фреймворков) |

Пример PSR-12:

```php
<?php

declare(strict_types=1);

namespace App;

class Example
{
    public function run(): void
    {
        foreach ($this->items as $item) {
            echo $item;
        }
    }
}
```

### Попробуй сам

Установите проверку стиля: `composer require --dev php-cs-fixer/php-cs-fixer` и запустите `vendor/bin/php-cs-fixer fix src/`.

### Задание

Перепишите любой ваш код из заданий выше по PSR-12: добавьте namespace, типы параметров и возврата, корректные отступы.

### Самопроверка

**Ответ:**

Проверьте себя по чек-листу: открывающая фигурная скобка на новой строке у классов и методов, 4 пробела отступа, один пробел вокруг операторов, типы у параметров и `: type`, пробел перед объявлением типа возврата.

## Проекты-практикумы

Три проекта возрастающей сложности. Каждый — готовое маленькое веб-приложение на чистом PHP.

### Проект 1. Контактная форма

- HTML-форма «Имя + email + сообщение» на `POST`.
- Валидация (`filter_var` для email, `strlen` для сообщения).
- Вывод ошибок рядом с полями, повторное заполнение полей.
- Отправка письма через `mail()` (опционально) или сохранение в `messages.json` через `json_encode`.
- Защита вывода `htmlspecialchars`.

### Проект 2. Мини-блог

Стек: SQLite + PDO.

- Таблицы `posts`, `comments`.
- Страницы: список постов, просмотр поста (`?id=`), форма добавления поста, форма комментария.
- Все обращения с данными — только через prepared statements.
- Счётчик просмотров поста через куку, чтобы не считать повторные заходы.
- Разделение на «свои» и «чужие» действия через `$_SESSION['user_id']`.

### Проект 3. TODO-менеджер с БД

- `tasks(id, title, done, created_at)` в SQLite (или MySQL через `mysql:` DSN).
- Действия: добавить, отметить выполненной, удалить — через формы; повторные `POST` безопасны (`POST/Redirect/GET`).
- Фильтр «Все / Активные / Выполненные» через `?filter=`.
- Подсчёт активных задач на странице.
- Оформление по PSR-12, всё через PHPStorm/VS Code + PHP.

### Читерство не запрещено, но осваивайте сами

Готовые решения — отличный способ учиться: читайте исходники маленьких проектов (например, блог-туториалы на dev.to), но каждый проект из списка напишите **сами**, прежде чем сравнивать.
