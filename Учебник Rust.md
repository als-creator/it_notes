# Руководство по Rust для новичков

**Rust** — системный язык программирования, разработанный Mozilla. Rust обеспечивает контроль памяти на уровне C/C++, но при этом гарантирует безопасность памяти без сборщика мусора. Компилятор Rust ловит ошибки памяти на этапе компиляции, что делает код надёжным и быстёр. Используется в операционных системах, браузерах, CLI-утилитах, веб-серверах и блокчейнах.

Практикум по языку программирования **Rust**. Здесь собрана теория, ASCII-схемы,
примеры для копирования, задания и самопроверка. Учебник рассчитан на edition Rust 2021
и актуальную стабильную версию компилятора (на момент написания — 1.7x–1.8x).

## Установка (rustup) и начало (cargo new, run, build)

**Что такое Rust?** Это системный язык программирования, созданный Mozilla Research
(а сейчас развиваемый независимой командой). Главные идеи Rust: безопасность памяти
**без сборщика мусора** и без утечек, высокая производительность (сравнимая с C/C++)
и выразительность современного языка. Компилятор Rust не даёт многим ошибкам (гонкам
данных, висячим ссылкам, буферным переполнениям) попасть в работающую программу ещё
на этапе компиляции.

**Как установить.** Официальный инструмент — `rustup`, менеджер инструментариев Rust.
Он ставит `rustc` (компилятор), `cargo` (менеджер пакетов и сборки) и `rustup` (сам
менеджер версий).

```bash
# Unix / Linux / macOS
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# После установки — добавить cargo/bin в PATH (скрипт делает это сам)
source "$HOME/.cargo/env"
```

Для Windows можно скачать установщик rustup-init.exe с официального сайта.

**Проверка установки:**

```bash
rustc --version
cargo --version
```

**Первый проект.** `cargo` — сердце экосистемы Rust. Он создаёт новый проект,
собирает, запускает, тестирует, ставит зависимости из [crates.io](https://crates.io).

```bash
cargo new hello_world
cd hello_world
```

Как выглядит структура нового проекта:

```
hello_world/
├── Cargo.toml      # манифест проекта (имя, зависимости, метаданные)
└── src/
    └── main.rs     # исходный код программы
```

Команды `cargo`:

```bash
cargo build            # скомпилировать (соберёт debug-версию, без запуска)
cargo run              # скомпилировать и запустить
cargo build --release  # оптимизированная сборка для продакшена
cargo check            # проверить, что код компилируется (быстро, без exe)
cargo test             # запустить тесты
```

**Файл `Cargo.toml`** — манифест. Выглядит так после `cargo new`:

```toml
[package]
name = "hello_world"
version = "0.1.0"
edition = "2021"

[dependencies]
```

Здесь `edition = "2021"` — версия языка. Это не «версия компилятора», а способ
совместимых обновлений: код, написанный на edition 2021, продолжит компилироваться
будущими компиляторами.

**Пример программы.** `cargo new` уже создал файл `src/main.rs`:

```rust
fn main() {
    println!("Hello, world!");
}
```

Запустим:

```bash
cargo run
```

Результат в консоли:

```
   Compiling hello_world v0.1.0 (/home/als/hello_world)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.4s
     Running `target/debug/hello_world`
Hello, world!
```

> `fn main()` — точка входа программы. `println!` — макрос вывода (обрати внимание
> на восклицательный знак: это макрос, а не функция; подробнее — в разделе о функциях).
> Каждая строка в Rust заканчивается точкой с запятой `;`.

### ASCII-схема: компиляция Rust

Как связаны `cargo` и `rustc`, и что происходит с вашим кодом:

```
┌───────────────────────────────────────────────────────────────┐
│                        Hi-Level: cargo                        │
│   cargo run ──► [собирает зависимости] ──► [вызывает rustc]    │
└───────────────────────────────┬───────────────────────────────┘
                                │ передаёт .rs файлы и флаги
                                ▼
┌───────────────────────────────────────────────────────────────┐
│   rustc (компилятор)                                          │
│   src/main.rs ──► [фронтенд: лексический разбор]               │
│              ──► [дерево разбора / AST]                        │
│              ──► [анализ типов + проверка заимствований]       │
│              ──► [генерация внутреннего представления]         │
│              ──► [оптимизации (в release)]                     │
│              ──► [бэкенд LLVM] ──► машинный код                │
└───────────────────────────────┬───────────────────────────────┘
                                │
                                ▼
                    target/debug/hello_world   (исполняемый файл)
```

Ключевая мысль: **проверка заимствований и безопасности памяти происходит на этапе
компиляции**, до того как программа куда-либо запустится. Компилятор Rust — это как
строгий ревьюер, который ловит ошибки до того, как они проявятся.

### Попробуй сам

Создай проект и добавь немного вывода:

```bash

cd proch
```

```rust

    println!("Привет, это мой первый проект!");
    println!("2 + 2 = {}", 2 + 2);
```

> но в реальных проектах старайся писать идентификаторы латиницей.

## Примитивные типы, переменные и неизменяемость

**Скалярные (примитивные) типы Rust:**

| Тип    | Описание                            | Пример                |
|--------|-------------------------------------|-----------------------|
| `i32`  | целое со знаком, 32 бита (по умолчанию) | `42`, `-7`           |
| `i64`  | целое со знаком, 64 бита           | `100000000000`        |
| `u8`   | целое без знака, 8 бит              | `255`                 |
| `u32`  | целое без знака, 32 бита            | `3000`                |
| `f64`  | число с плавающей точкой (по умолчанию) | `3.14`, `-0.5`     |
| `f32`  | число с плавающей точкой, 32 бита   | `2.5`                 |
| `bool` | логическое значение                 | `true`, `false`       |
| `char` | один Юникод-символ                  | `'a'`, `'Ж'`, `'😀'`   |
| `()`   | «кортеж из нуля», пустое значение   | `()`                  |

Про целые числа: суффиксы `i`/`u` означают *signed*/`unsigned` (со знаком / без знака),
а числа — разрядность. `i8`, `i16`, `i32`, `i64`, `i128`, `usize` (разрядность зависит
от архитектуры — 64 бита на 64-битных системах) и аналогичные `u*`.

**Переменные — неизменяемость по умолчанию.** Ключевое слово `let` объявляет
переменную. Самая частая ошибка новичка — попытки изменить `let`-переменную без
`mut`:

```rust
fn main() {
    let x = 5;
    // x = 6;  // ОШИБКА: cannot assign to `x` — переменная не mut
    println!("x = {}", x);
}
```

Чтобы разрешить изменение, добавь `mut`:

```rust
fn main() {
    let mut x = 5;
    println!("x = {}", x);  // 5
    x = 6;
    println!("x = {}", x);  // 6
    x += 1;
    println!("x = {}", x);  // 7
}
```

**Константы (`const`)** — в отличие от `let`, константа всегда неизменяема, должна
иметь явный тип и объявляется с `const`:

```rust
const MAX_HEIGHT: u32 = 1000;
```

**Тип можно указать явно** — двоеточие после имени:

```rust
let число: i64 = 100;
let pi: f64 = 3.14159;
let ready: bool = true;
let letter: char = 'Ж';
```

**Затенение (shadowing).** Можно объявлять новую переменную с тем же именем — новое
значение «затеняет» старое. Это не то же самое, что `mut`, потому что создаётся новая
переменная:

```rust
fn main() {
    let x = 5;
    let x = x + 1;   // новая переменная x = 6
    let x = x * 2;   // ещё одна новая x = 12
    println!("x = {}", x);  // 12
}
```

**Вывод типа.** Rust выводит типы сам. Про `42` компилятор решит, что это `i32`
(целое по умолчанию), про `3.14` — `f64`.

### Попробуй сам

```rust
fn main() {
    let mut счёт = 0_u32;
    счёт += 1;
    println!("счёт = {}", счёт);

    let число: i64 = 1_000_000_000;      // подчёркивания — просто разделители
    println!("число = {}", число);

    let имя = "Алекс";
    let инициал: char = 'А';
    println!("{} начинается с {}", имя, инициал);

    let логично = true;
    println!("логично = {}", логично);

    const СКОРОСТЬ_СВЕТА: u32 = 299_792_458;
    println!("скорость света ≈ {}", СКОРОСТЬ_СВЕТА);
}
```

## Функции

Функции объявляются через `fn`. Имена функций — в стиле snake_case (все строчные,
слова через подчёркивание).

```rust
fn greet() {
    println!("Привет!");
}

fn main() {
    greet();
}
```

**Параметры** объявляются как `имя: Тип`. В Rust нет «неявных» типов параметров.

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let result = add(5, 7);
    println!("{}", result); // 12
}
```

Обрати внимание: **последнее выражение без `;` — это возвращаемое значение.** В
функции `add` нет `return` и нет точки с запятой после `a + b` — оно и возвращается.
Такой коди-стиль называют *tail expression*.

Можно и через `return`, но это реже:

```rust
fn add(a: i32, b: i32) -> i32 {
    return a + b;
}
```

**Разница выражений и инструкций:**

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1   // без ';' — это значение блока
    };
    println!("{}", y); // 4
}
```

**Макросы.** `println!`, `vec!`, `format!` — это макросы (видишь `!`). Макросы
раскрываются в код на этапе компиляции. `println!` — самый используемый.

Специальные заполнители в `println!`:

```rust
fn main() {
    let name = "Оля";
    let age = 30;

    println!("{} — {} лет", name, age);   // {} — позиционные

    println!("{name} — {age} лет");       // именованные (Rust 1.58+)

    println!("{value} в hex = {value:#x}", value = 255); // с параметром

    // формат с шириной
    println!("{:>10}", "справа");         // выравнивание вправо на 10 позиций
    println!("{:.2}", 3.14159);           // два знака после запятой
}
```

## Владение и заимствование — ключевая тема

Это **самая важная** и отличительная концепция Rust, из-за которой язык и получил
свою репутацию. Прочитай внимательно, разберись на схемах, а потом поиграй с кодом.

### Правила владения

Три простых правила, которые вызубри наизусть:

1. **У каждого значения в Rust есть владелец (owner).**
2. **В каждый момент времени у значения может быть ровно один владелец.**
3. **Когда владелец выходит из области видимости, значение удаляется (drop), память освобождается.**

Владение — это способ задать срок жизни данных и избежать ручного управления памятью
(`malloc`/`free`), но в отличие от сборщика мусора — **детерминированно** и без паузы.

### Схема: безопасность памяти (main → data)

Что гарантирует компилятор на схеме «кто владеет → кто ссылается»:

```
fn main() {
    let data = String::from("привет");     data ──владеет──► "привет"
    let r = &data;                          r ──заимствует──► data
    println!("{}", r);
}   ← ВЫХОД из main: сначала умирает r (ссылка),
      потом data (владелец) — память освобождена.
```

```
              владеет (ровно один)
    main ──────────────────────────► data  ("привет")
      │                               ▲
      │  заимствует (r = &data)       │  ссылка не «переживает»
      │  на время жизни r             │  владельца
      └───────────────────────────────┘

  ОШИБКА (не соберётся):
      let r;
      {
          let data = String::from("x");
          r = &data;        // data умрёт в конце блока
      }                     // r останется «висячей ссылкой»
      println!("{}", r);    // NO: 'data' does not live long enough
```

Именно благодаря этой схеме Rust устраняет целый класс ошибок (висячие ссылки,
двойное освобождение, гонки данных) на этапе компиляции — без сборщика мусора.
Подробнее про lifetimes — в соответствующем разделе ниже.

### Схема: владение (ownership)

Представь, что данные — это коробка, а владелец — человек, который держит коробку:

```
Пример: let s1 = String::from("hello");

             ┌──────────┐
             │ "hello"  │   <- данные (куча)
             └────▲─────┘
                  │ владеет
             ┌────┴─────┐
             │   s1     │   <- переменная (стек, указатель на кучу)
             └──────────┘
                  владелец s1
```

**Перемещение (move).** Когда присваиваем `let s2 = s1;` — владение *перемещается*
от `s1` к `s2`. Строка `s1` «умирает» и больше не доступна:

```
            let s2 = s1;   (s1 moves into s2)

             ┌──────────┐
             │ "hello"  │
             └────▲─────┘
                  │ владеет (после переезда)
             ┌────┴─────┐
             │  s2 (был s1) │
             └──────────┘
             s1 больше НЕдоступна!
```

Почему так? Строка `String` хранит данные в куче и держит указатель на них. Если бы
`let s2 = s1;` просто скопировало `s1` в `s2`, оба указателя указывали бы на одно
место в куче. Тогда при выходе из области видимости Rust дважды освободил бы одну и
ту же память — это баг двойного освобождения, опасный и трудноуловимый в C. Rust
решает проблему просто: **перемещением**, при котором у данных всегда один владелец.

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;               // владение переместилось в s2

    // println!("{}", s1);     // ОШИБКА: borrow of moved value: `s1`
    println!("{}", s2);        // ок — "hello"
}
```

Компилятор вам прямо так и скажет: «value borrowed here after move».

**Копирование.** Примитивные типы (`i32`, `f64`, `bool`, `char`) реализуют трейт
`Copy` — их присваивание **копирует**, а не перемещает. Поэтому оба работают:

```rust
let a = 5;
let b = a;      // копия
println!("{} {}", a, b);   // 5 5 — обе живые!
```

Почему? Потому что примитивы целиком живут на стеке — там просто нет указателя на
кучу, копировать безопасно и дёшево.

Типы `String`, `Vec`, `HashMap` — не `Copy`, они перемещаются.

### Схема: стек и куча

Чтобы понять, почему `String` ведёт себя так, а `i32` иначе, разберёмся со стеком и
кучей.

```
ПАМЯТЬ ПРОЦЕССА
┌──────────────────────────────────────────────┐
│  СТЕК (stack)                                 │
│  ─ быстрый, LIFO                             │
│  ─ данные фиксированного размера (числа,      │
│    ссылки, фиксированные структуры)           │
│  ─ автоматически освобождается при выходе     │
│    из области видимости                       │
│                                              │
│   ┌───────┐   ┌───────┐                      │
│   │ 5     │   │ 3.14  │        <- i32, f64   │
│   └───────┘   └───────┘                      │
│              ┌──────────────┐                │
│              │ s: длина,    │                │
│              │    вмест.,   │                │
│              │    pointer───┼──┐             │
│              └──────────────┘  │             │
├────────────────────────────────┼─────────────┤
│  КУЧА (heap)                   │             │
│  ─ медленнее, произвольный     │             │
│    доступ                       │             │
│  ─ данные переменного размера  ▼             │
│   ┌──────────────────────────┐               │
│   │  "Привет, это длинная    │               │
│   │   строка в куче..."       │               │
│   └──────────────────────────┘               │
└──────────────────────────────────────────────┘
```

- **Стек**: быстрые маленькие данные фиксированного размера. `i32`, `f64`, `bool`,
  `char`, а также *структуры*, чей размер известен на этапе компиляции.
- **Куча**: большие или изменяемые по размеру данные — `String`, `Vec`, `Box`.
  Переменная на стеке хранит указатель (адрес) на данные в куче.

Важно: `String` на стеке — это тройка `(указатель, длина, вместимость)`, а сами
символы лежат в куче. Именно поэтому копирование `String` «по значению» опасное —
оба указателя на один кусок кучи.

### Схема: заимствование (borrowing)

`&` — это **ссылка** (заимствование). Вместо того чтобы отдавать владение, мы даём
кому-то «почитать» или «поправить» данные *во временное пользование*, не передавая
право владения. Владение остаётся у исходного владельца.

```
let s = String::from("hello");
let r = &s;          // r — неизменяемая ссылка на s (заимствование на чтение)

             ┌──────────┐
             │ "hello"  │
             └────▲─────┘
                  │ владеет
             ┌────┴─────┐
             │   s      │   <- владелец
             └──▲───────┘
                │ заимствует (читает)
             ┌──┴───────┐
             │  r = &s  │   <- ссылка (не владелец!)
             └──────────┘
```

Ссылок (на чтение) может быть много — столько друзей могут читать книгу, пока никто
не пишет в неё:

```rust
let s = String::from("hello");
let r1 = &s;
let r2 = &s;      // можно: сколько угодно неизменяемых
let r3 = &s;
println!("{} {} {}", r1, r2, r3);
```

**Изменяемая ссылка `&mut`** — только **одна** одновременно. Как один человек может
править документ, и никто другой не должен его в этот момент читать или писать:

```rust
let mut s = String::from("hello");
let r = &mut s;   // одна изменяемая ссылка
r.push_str(" world");
println!("{}", r); // "hello world"
// после этого r больше не используется — можно делать новые заимствования
```

**Правила заимствования** (тут самая частая ошибка компилятора):

1. В любой момент времени у значения может быть **либо** сколько угодно неизменяемых
   ссылок (`&`), **либо** одна изменяемая ссылка (`&mut`).
2. Ссылки всегда должны быть действительными (не могут «пережить» данные, на которые
   указывают) — это про lifetimes, разберём позже.

Почему одно `&mut` одновременно? Потому что несколько `&mut` одновременно создали бы
гонку данных (data race): два потока могли бы писать в одно место. Rust запрещает
это ещё на этапе компиляции — ты не сможешь собрать программу с гонкой данных.

```rust
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;          // ок
    let r2 = &s;          // ок
    println!("{} {}", r1, r2);

    // здесь r1 и r2 вышли из области видимости (последнее использование)
    let r3 = &mut s;      // теперь ок — одна mut-ссылка
    r3.push_str(" world");
    println!("{}", r3);
}
```

### Владение в функциях

Передача значения в функцию — это перемещение (если не `Copy`). Значение «переезжает»
внутрь функции, и снаружи больше не доступно:

```rust
fn take_ownership(s: String) {
    println!("Я получил: {}", s);
    // здесь s удаляется
}

fn main() {
    let s = String::from("hello");
    take_ownership(s);
    // println!("{}", s);  // ОШИБКА: value moved here
}
```

Если нужно, чтобы значение осталось, — **заимствуй** его ссылкой:

```rust
fn borrow_length(s: &String) -> usize {
    s.len()   // только читаем
}

fn main() {
    let s = String::from("hello");
    let len = borrow_length(&s);  // передаём ссылку, s сохраняет владение
    println!("Длина '{}' = {}", s, len);  // s всё ещё доступна
}
```

А чтобы функция могла *изменить* строку, но не отнять владение, — `&mut String`:

```rust
fn append_world(s: &mut String) {
    s.push_str(" world");
}

fn main() {
    let mut s = String::from("hello");
    append_world(&mut s);
    println!("{}", s);  // "hello world"
}
```

### Привычка: заимствуй, когда не нужен новый владелец

Хорошая практика: если функция только читает данные, передавай `&`, а не значение.
Так ты избежишь лишних перемещений и копий. Для строк повсеместно используют тип
`&str` (срез, see ниже) вместо `&String` — об этом в следующем разделе.

### Попробуй сам

```rust
fn main() {
    // Владение и перемещение
    let s1 = String::from("rust");
    let s2 = s1;
    println!("{}", s2);

    // Копирование примитивов
    let x = 5;
    let y = x;
    println!("{} {}", x, y);

    // Заимствование на чтение
    let s = String::from("данные");
    let r1 = &s;
    let r2 = &s;
    println!("{} {}", r1, r2);
    // s всё ещё жив, мы только читали

    // Изменяемое заимствование
    let mut t = String::from("a");
    {
        let m = &mut t;
        m.push_str("b");
    }
    println!("{}", t);
}
```

## Срезы (slices)

**Срез** — это «окно» в другие данные, не владеющее ими. Срез — это ссылка на
непрерывную последовательность элементов. Тип строкового среза — `&str`.

```rust
fn main() {
    let s = String::from("hello world");
    let hello = &s[0..5];   // срез с 0 по 5 (не включая 5) -> "hello"
    let world = &s[6..11];  // срез с 6 по 11 -> "world"

    println!("{} {}", hello, world); // hello world
}
```

`&s[0..5]` — берём срез строки `s`. Квадратные скобки с диапазоном `..`:

- `[0..5]` — от 0 (включительно) до 5 (не включая).
- `[..5]`  — от начала до 5.
- `[5..]`  — от 5 до конца.
- `[..]`   — вся строка.

Важно: индексация строки напрямую через символы **не работает** для кириллицы и
эмодзи, потому что в UTF-8 символы могут занимать несколько байт. Срезы по байтам
могут «разрезать» символ пополам — тогда программа паникует. Срезы `&str` безопасны
на границах символов, если режем по правильным границам. Реальный код чаще работает
с `&str` целиком, а не по байтовым окнам.

```rust
fn main() {
    let s = "Привет мир";  // &str — строковый литерал (это уже срез!)
    println!("Первое слово: {}", &s[..6]); // "Привет" — 6 байт (по 2 байта на букву)

    // Осторожно: "Прив" это 5 байт, а буква "и" занимает 2 байта?
    // "Прив" = П(2) р(2) и(2) в(2) = 8 байт! Подсчёт байтов, не символов.
}
```

Постой, здесь важный нюанс. Давай аккуратно. Кириллические буквы в UTF-8 занимают
по 2 байта. `"Привет"` = 6 букв × 2 байта = 12 байт. Если бы я написал `&s[..6]`,
это разрезало бы строку на границе «Пр» (4 байта) + 2 байта = ровно между буквами,
это валидно. Лучше не нагружать срезы по байтам кириллицей в учебнике. Разберём
безопасный вариант ниже в «Попробуй сам».

**Функция может принимать `&str`** — это самый гибкий способ получать строки:

```rust
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &byte) in bytes.iter().enumerate() {
        if byte == b' ' {
            return &s[0..i];
        }
    }
    &s[..]
}

fn main() {
    let s = String::from("hello world");
    // можно передать и &str-литерал, и &String — &str гибче &String
    let word = first_word(&s[..]);
    println!("{}", word); // hello
}
```

Заметь: `first_word` возвращает срез, связанный с входной строкой. Rust гарантирует
через lifetimes, что возвращаемый срез не переживёт входную строку.

### Попробуй сам (безопасный, для кириллицы)

```rust
fn main() {
    let s = String::from("rust язык");

    let word = first_word(&s);
    println!("Первое слово: {}", word); // rust

    let whole: &str = &s[..];
    println!("Вся строка: {}", whole);

    // срезы по символам через char_indices
    let text = "котик";
    // Осторожно: срез по байтам text[0..2] = "ко" (2 буквы по 2 байта)
    println!("Первые 2 байта = {:?}", &text[0..2]); // "ко"
}

fn first_word(s: &str) -> &str {
    match s.find(' ') {
        Some(pos) => &s[..pos],
        None => &s[..],
    }
}
```

Примечание: `s.find(' ')` возвращает `Option<usize>` с позицией первого пробела.
В кириллице пробел — один байт, так что `&s[..pos]` безопасен, ведь мы режем по
границе, найденной самим Rust.

## Структуры и методы

**Структура (`struct`)** — способ сгруппировать связанные данные. Объявляется через
`struct`, поля через `имя: Тип`.

```rust
struct User {
    name: String,
    age: u32,
    active: bool,
}

fn main() {
    let user = User {
        name: String::from("Аня"),
        age: 30,
        active: true,
    };

    println!("{}", user.name);
}
```

**Изменяемость полей.** Если нужно менять поля — переменная-владелец должна быть
`mut`:

```rust
let mut user = User { name: String::from("Аня"), age: 30, active: true };
user.age += 1;
```

**Функция для построения структуры** (удобна, когда у тебя много полей):

```rust
fn build_user(name: String, age: u32) -> User {
    User { name, age, active: true }
}
```

Заметил синтаксис `name` без `name: name`? Это **сокращение для полей**: если имя
переменной совпадает с именем поля, можно писать просто `name`.

**Обновление полей из другой структуры** — `..`:

```rust
let user2 = User {
    name: String::from("Боря"),
    ..user   // остальные поля взяты из user
};
```

**Кортежные структуры (tuple structs)** — без имён полей:

```rust
struct Color(u8, u8, u8);
struct Point(f64, f64);

fn main() {
    let origin = Point(0.0, 0.0);
    let red = Color(255, 0, 0);
    println!("red = ({}, {}, {})", red.0, red.1, red.2);
}
```

**Единичноподобные структуры** (unit struct) — без полей:

```rust
struct AlwaysRed;
```

**Методы через `impl`.** Методы — это функции, привязанные к типу. Первый параметр
метода — `self` (или `&self`, `&mut self`). Реализуются внутри блока `impl`:

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // &self — метод на чтение
    fn area(&self) -> u32 {
        self.width * self.height
    }

    // self — метод, потребляющий значение (забирает владение)
    fn describe(self) -> String {
        format!("{}x{} прямоугольник", self.width, self.height)
    }

    // &mut self — метод, меняющий значение
    fn scale(&mut self, factor: u32) {
        self.width *= factor;
        self.height *= factor;
    }
}

fn main() {
    let mut rect = Rectangle { width: 10, height: 5 };
    println!("Площадь: {}", rect.area());      // 50
    rect.scale(2);
    println!("После мастабирования: {}x{}", rect.width, rect.height); // 20x10
    println!("{}", rect.describe());
}
```

**Ассоциированная функция** — функция, не принимающая `self`. Вызывается через
`Тип::имя()`. Их часто используют как конструкторы:

```rust
impl Rectangle {
    fn square(size: u32) -> Rectangle {
        Rectangle { width: size, height: size }
    }
}

// вызов:
let sq = Rectangle::square(5);
```

> `String::from(...)`, `Vec::new()` — это как раз ассоциированные функции.

### Попробуй сам

```rust
struct Book {
    title: String,
    author: String,
    pages: u32,
}

impl Book {
    fn new(title: &str, author: &str, pages: u32) -> Book {
        Book {
            title: String::from(title),
            author: String::from(author),
            pages,
        }
    }

    fn summary(&self) -> String {
        format!("«{}» — {} ({} стр.)", self.title, self.author, self.pages)
    }

    fn is_long(&self) -> bool {
        self.pages > 300
    }
}
```

**Перечисление (`enum`)** задаёт набор возможных значений. Каждый вариант может нести
свои данные:

```rust
enum Direction {
    North,
    South,
    East,
    West,
}

    match d {
        Direction::North => String::from("на север"),
        Direction::South => String::from("на юг"),
        Direction::East => String::from("на восток"),
        Direction::West => String::from("на запад"),
    }
}

fn main() {
    println!("{}", describe(Direction::North));
}
```

**Варианты с данными:**

```rust
enum Message {
    Quit,                       // без данных
    Move { x: i32, y: i32 },    // именованные поля
    Write(String),              // один String
    Color(u8, u8, u8),          // кортеж
}
```

**`match` — мощный `switch`.** Он разбирает значение по вариантам и должен покрыть
все возможные случаи (компилятор это проверит). Руки могут развязаться — match
возвращает значение:

```rust
fn step(dir: Direction) -> (i32, i32) {
    match dir {
        Direction::North => (0, 1),
        Direction::South => (0, -1),
        Direction::East  => (1, 0),
        Direction::West  => (-1, 0),
    }
}
```

**`Option` и `match`.** `Option<T>` — базовый тип Rust для «значение может отсутствовать».
Он есть в прелюдии (не нужно импортировать). Варианты — `Some(value)` и `None`:

```rust
fn divide(a: f64, b: f64) -> Option<f64> {
    if b == 0.0 { None } else { Some(a / b) }
}

fn main() {
    let result = divide(10.0, 2.0);
    match result {
        Some(value) => println!("Результат: {}", value),
        None => println!("Деление на ноль!"),
    }
}
```

**`if let`** — сокращение для match, когда нужен только один вариант:

```rust
let result = divide(10.0, 0.0);
if let Some(value) = result {
    println!("{}", value);
} else {
    println!("Нет результата");
}
```

**`_` — широковещательный паттерн** (*wildcard*) для «всех остальных»:

```rust
let x = 7;
match x {
    1 => println!("один"),
    2 => println!("два"),
    _ => println!("какое-то другое число"),
}
```

**`let else` (Rust 1.65+).** Короткий способ выйти из None-ветки:

```rust
fn main() {
    let some_opt = Some(5);
    let Some(value) = some_opt else {
        println!("Нет значения — выходим");
        return;
    };
    println!("value = {}", value);
}
```

## Модули

Модули организуют код в иерархию и управляют видимостью (чьи элементы доступны где).
Объявляются через `mod`.

**Создание модуля в файле:**

```rust
// src/main.rs
mod greetings {
    pub fn hello() -> String {
        String::from("Привет из модуля!")
    }
}

fn main() {
    println!("{}", greetings::hello());
}
```

**Ключевые модификаторы видимости:**

- `pub` — доступно всем, кто видит модуль.
- по умолчанию (без `pub`) — доступно только внутри текущего модуля и его потомков.

**Модуль в отдельном файле.** Объявим `src/greetings.rs`:

```rust
// src/greetings.rs
pub fn hello() -> String {
    String::from("Привет из отдельного файла!")
}
```

А в `main.rs` подключим:

```rust
// src/main.rs
mod greetings;   // подключит файл src/greetings.rs

fn main() {
    println!("{}", greetings::hello());
}
```

**Модули в папках** (`src/shapes/area.rs`):

```
src/
├── main.rs
└── shapes/
    ├── mod.rs      # mod shapes { ... } — точка входа в модуль
    └── area.rs
```

`src/shapes/mod.rs`:

```rust
// src/shapes/mod.rs
pub mod area;   // публичный подмодуль area
```

`src/shapes/area.rs`:

```rust
// src/shapes/area.rs
pub fn circle(radius: f64) -> f64 {
    std::f64::consts::PI * radius * radius
}
```

В `main.rs`:

```rust
mod shapes;

fn main() {
    println!("{}", shapes::area::circle(2.0));
}
```

**`use` — импорт в область видимости.** Сокращает пути:

```rust
use shapes::area::circle;

fn main() {
    println!("{}", circle(2.0));  // вместо shapes::area::circle
}
```

**`pub use` (реэкспорт)** — делает путь короче для внешнего пользователя:

```rust
// в shapes/mod.rs
pub use area::circle;  // теперь можно shapes::circle
```

**`self` и `super`** в путях: `super::` — родительский модуль, `self` — текущий.

## Стандартные коллекции (Vec, HashMap)

**`Vec<T>`** — динамический массив, хранит элементы одного типа `T`.

```rust
fn main() {
    // создание
    let mut v: Vec<i32> = Vec::new();
    v.push(1);
    v.push(2);

    // макрос vec!
    let mut nums = vec![10, 20, 30];
    nums.push(40);

    // доступ по индексу (паника, если нет)
    println!("{}", nums[0]);

    // безопасный доступ через get -> Option
    match nums.get(1) {
        Some(x) => println!("второй: {}", x),
        None => println!("нет такого индекса"),
    }

    // итерация по ссылкам (не перемещая владение)
    for n in &nums {
        print!("{} ", n);  // 10 20 30 40
    }
    println!();

    // итерация по изменяемым ссылкам
    for n in &mut nums {
        *n *= 2;
    }
    println!("{:?}", nums); // [20, 40, 60, 80]

    // удаление последнего
    nums.pop();
    println!("{:?}", nums); // [20, 40, 60]

    // длина и проверка на пустоту
    println!("len = {}, empty = {}", nums.len(), nums.is_empty());
}
```

**Полезные методы `Vec`:** `push`, `pop`, `len`, `is_empty`, `get`, `first`, `last`,
`contains`, `sort`, `reverse`, `iter`, `retain`, `truncate`, `clear`.

**`HashMap<K, V>`** — ассоциативный массив (словарь). Ключ → значение.

```rust
use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();

    scores.insert(String::from("Синие"), 10);
    scores.insert(String::from("Жёлтые"), 50);

    // доступ
    let team = "Синие";
    let score = scores.get(team).copied().unwrap_or(0);
    println!("score for {}: {}", team, score);

    // перебор
    for (key, value) in &scores {
        println!("{}: {}", key, value);
    }

    // проверка наличия ключа и вставка по умолчанию
    let key = String::from("Зелёные");
    scores.entry(key).or_insert(0);   // вставит 0, если ключа нет

    // подсчёт вхождений
    let mut counts = HashMap::new();
    for word in ["яблоко", "банан", "яблоко", "вишня"] {
        let counter = counts.entry(word).or_insert(0);
        *counter += 1;
    }
    println!("{:?}", counts); // {"банан": 1, "яблоко": 2, "вишня": 1}
}
```

`entry(...).or_insert(...)` — идиоматичный способ «взять значение по ключу или
вставить значение по умолчанию», возвращает изменяемую ссылку на значение.

## Обработка ошибок (Result, Option, unwrap, ?)

В Rust нет исключений. Ошибки бывают двух категорий:

- **Восстановимые** — представлены типом `Result<T, E>`.
- **Невосстановимые** — приводят к панике (`panic!`).

**`Option<T>`** — «есть значение или нет» (см. раздел про match):

- `Some(value)` — есть,
- `None` — нет.

**`Result<T, E>`** — «получилось или нет, и если нет — какая ошибка»:

- `Ok(value)` — успех,
- `Err(error)` — ошибка.

Такой тип описан в стандартной библиотеке:

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

**Пример с `Result`.** Разбор строки в число возвращает `Result`:

```rust
fn main() {
    let num = "42".parse::<i32>();
    // num — это Result<i32, ParseIntError>
    match num {
        Ok(n) => println!("Это число: {}", n),
        Err(e) => println!("Ошибка: {}", e),
    }

    let bad = "abc".parse::<i32>();
    match bad {
        Ok(n) => println!("Это число: {}", n),
        Err(e) => println!("Ошибка разбора: {}", e),
    }
}
```

**Функция может возвращать `Result`:**

```rust
use std::fs::File;
use std::io::{self, Read};

fn read_username_from_file() -> Result<String, io::Error> {
    let mut file = File::open("username.txt")?;
    let mut content = String::new();
    file.read_to_string(&mut content)?;
    Ok(content)
}
```

**Оператор `?`.** Внутри функции `?` после выражения типа `Result` делает: если
`Ok(x)` — продолжить со значением `x`; если `Err(e)` — немедленно вернуть `Err(e)`
из функции. Это огромное упрощение против ручных match на каждом шаге.

`?` можно использовать и в `Option`: если `None` — вернуть `None` из функции.

```rust
fn sqrt_of(input: &str) -> Option<f64> {
    let real = input.parse::<f64>().ok()?;   // если разбор не удался -> None
    if real < 0.0 {
        None
    } else {
        Some(real.sqrt())
    }
}

fn main() {
    println!("{:?}", sqrt_of("16"));   // Some(4.0)
    println!("{:?}", sqrt_of("abc"));  // None
    println!("{:?}", sqrt_of("-1"));   // None
}
```

**`unwrap` и `expect`.** Быстрый способ получить значение или упасть:

```rust
let n = "42".parse::<i32>().unwrap();   // паникует, если Err
let m = "42".parse::<i32>().expect("не число");  // с сообщением об ошибке
```

Используй их для кратокого прототипирования и в местах, где ошибка заведомо
невозможна. В «боевом» коде предпочитай `match` или `?`.

### Попробуй сам

```rust
    }

```

## Generics и traits (базово)

**Generics (обобщённые типы)** позволяют писать функции и структуры, работающие с
любым типом, без дублирования кода. Синтаксис — угловые скобки `<T>`.

```rust
// T — произвольный тип
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut largest = &list[0];
    for item in list {
        if item > largest {
            largest = item;
        }
    }
    largest
}

fn main() {
    let numbers = vec![34, 50, 25, 100, 65];
    println!("{}", largest(&numbers));  // 100

    let chars = vec!['y', 'm', 'a', 'q'];
    println!("{}", largest(&chars));    // y
}
```

Здесь `T: PartialOrd` — **trait bound**: говорит компилятору, что `T` должен
поддерживать сравнение `>`. Без этого мы не можем написать `item > largest`.

**Generics в структурах:**

```rust
struct Point<T> {
    x: T,
    y: T,
}

fn main() {
    let integer = Point { x: 5, y: 10 };    // Point<i32>
    let float = Point { x: 1.0, y: 4.0 };   // Point<f64>
    println!("{}, {}", integer.x, float.y);
}
```

**Traits — общий интерфейс (вроде интерфейсов в других языках).** Описывают
поведение, которое тип должен реализовать. Пример с трейтом `Summary`:

```rust
trait Summary {
    fn summarize(&self) -> String;
}

struct Article {
    title: String,
    author: String,
}

// реализуем трейт для Article
impl Summary for Article {
    fn summarize(&self) -> String {
        format!("«{}» — {}", self.title, self.author)
    }
}

struct Tweet {
    text: String,
    likes: u32,
}

impl Summary for Tweet {
    fn summarize(&self) -> String {
        format!("{} ({} лайков)", self.text, self.likes)
    }
}
```

**Trait bound в функции:**

```rust
// любой тип, реализующий Summary
fn print_summary<T: Summary>(item: &T) {
    println!("{}", item.summarize());
}

fn main() {
    let a = Article { title: String::from("Rust"), author: String::from("Игорь") };
    let t = Tweet { text: String::from("hello"), likes: 3 };

    print_summary(&a);
    print_summary(&t);
}
```

**Важная особенность трейтов:** для того чтобы метод трейта работал на типе, трейт
должен быть в области видимости (импортирован). Многие трейты уже в прелюдии.

**Trait как параметр через `impl Trait`** (более короткая запись):

```rust
fn print_summary(item: &impl Summary) {
    println!("{}", item.summarize());
}
```

## Lifetimes — кратко

Lifetimes (время жизни ссылок) — механизм, с помощью которого компилятор гарантирует,
что ссылки не «переживут» данные, на которые указывают. Это проверка на **висячие
ссылки** (dangling references).

Синтаксис: `'a` (апостроф + имя). Это «жизненная метка».

**Проблема висячей ссылки:**

```rust
fn main() {
    let r;                 // пустая ссылка
    {
        let x = 5;
        r = &x;            // ВНИМАНИЕ: x умрёт здесь
    }
    // здесь брать у r значение нельзя — x уже не существует
    // println!("{}", r);  // ОШИБКА: `x` does not live long enough
}
```

Компилятор ловит это. Lifetimes — то, как Rust это выражает.

**Схема: lifetimes визуально**

```
fn main() {
    let r;
    {
        let x = 5;
        r = &x;      // ссылка r указывает на x
    }
}

Время жизни значений:

        начало main              конец main
           │                          │
           │  'a (жизнь x)           │
           │  ├──────────────────────┼─────────────►  (x живёт дольше)
           │     'b (жизнь r)        │
           │     └───────────┘        │
           │                          │
           ▼                          ▼

Компилятор требует: 'b (срок жизни ссылки) НЕ должен превышать 'a (срок жизни
данных). Здесь 'b длиннее 'a? Нет — надо, чтобы ссылка не жила дольше данных.

Ошибка: r (живёт до конца main) ссылается на x (живёт только внутри блока).
```

**Элизия lifetime.** В большинстве функций не нужно писать `'a`, потому что компилятор
выводит их сам. Правила элизии: у функции с одним входным параметром-ссылкой
возвращаемая ссылка получает то же время жизни, что и параметр.

**Пример, где lifetimes нужны явно** — когда несколько входных ссылок:

```rust
// longest: вернёт ссылку, которая живёт не меньше, чем оба входных параметра
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

fn main() {
    let a = String::from("короткая");
    let b = String::from("намного, намного длиннее");
    let result = longest(&a, &b);
    println!("Длиннее: {}", result);
}
```

`<'a>` означает: «возвращаемая ссылка будет жить не дольше, чем любая из входных».
Это гарантия, что возвращённая ссылка не станет висячей.

**Lifetimes в структурах:** структура, хранящая ссылку, должна указать lifetime:

```rust
struct Highlight<'a> {
    text: &'a str,
}

fn main() {
    let content = String::from("Какой-то длинный текст");
    let h = Highlight { text: &content };
    println!("{}", h.text);
}
```

### Схема: lifetimes в структуре

```
struct Highlight<'a> { text: &'a str }

┌─────────────────────────────────────────────────────┐
│              область видимости main                  │
│                                                     │
│   ┌───────────────┐  ┌───────────────┐              │
│   │  content:     │  │  h:           │              │
│   │  String       │  │  Highlight<'a>│              │
│   │  ("текст...") │  │  { text: &'a }│              │
│   └───────────────┘  └───────┬───────┘              │
│                              │ 'a                    │
│                              ▼ (ссылка на content)   │
└─────────────────────────────────────────────────────┘

Lifetime 'a связывает: h.text живёт НЕ дольше, чем content.
Кто живёт короче — тот и граница для 'a. Тут content живёт до конца main,
а h ссылается на него — компилятор это проверил.
```

## Тесты (cargo test) и clippy

**`cargo test`** — запускает тесты проекта. Тесты — это функции с атрибутом `#[test]`.
Проверки через макросы `assert!`, `assert_eq!`, `assert_ne!`.

Пример модульного теста:

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn is_even(n: i32) -> bool {
    n % 2 == 0
}

#[cfg(test)]
mod tests {
    use super::*;   // импортируем всё из внешнего модуля

    #[test]
    fn test_add() {
        assert_eq!(add(2, 3), 5);
        assert_eq!(add(-1, 1), 0);
    }

    #[test]
    fn test_is_even() {
        assert!(is_even(4));
        assert!(!is_even(7));
    }

    #[test]
    fn test_negative() {
        // если бы это было неверно, тест бы упал
        assert_ne!(add(1, 1), 3);
    }
}
```

Запуск:

```bash
cargo test
```

Вывод покажет, какие тесты прошли (test result: ok). Если тест падает — `panic`.

**`#[should_panic]`** — тест, ожидающий панику:

```rust
#[test]
#[should_panic]
fn test_panic_expected() {
    let v = vec![1, 2, 3];
    let _x = v[10];   // паника: индекс вне границ
}
```

**`cargo clippy`** — линтер, ищет неидиоматичные места в коде и даёт советы без
изменения поведения. Есть два вида кода: работающий и идиоматичный. Clippy помогает
со вторым.

```bash
cargo clippy
# или с фиксацией всех предлагаемых изменений:
cargo clippy --fix
```

Пример, что замечает clippy — используй `{}` вместо `format!` в `println!`,
лишние `&` и т.д.

### Проект 1: Калькулятор

Создай консольный калькулятор, поддерживающий `+ - * /` и целые числа.

```rust
use std::io::{self, Write};

fn main() {
    loop {
        print!("> ");
        io::stdout().flush().unwrap();

        let mut line = String::new();
        if io::stdin().read_line(&mut line).is_err() {
            break;
        }
        let line = line.trim();
        if line == "quit" || line == "exit" {
            break;
        }

        let parts: Vec<&str> = line.split_whitespace().collect();
        if parts.len() != 3 {
            println!("Формат: число операция число");
            continue;
        }

        let a: f64 = match parts[0].parse() {
            Ok(v) => v,
            Err(_) => { println!("Не число: {}", parts[0]); continue; }
        };
        let b: f64 = match parts[2].parse() {
            Ok(v) => v,
            Err(_) => { println!("Не число: {}", parts[2]); continue; }
        };

        let result = match parts[1] {
            "+" => Some(a + b),
            "-" => Some(a - b),
            "*" => Some(a * b),
            "/" => if b == 0.0 { println!("деление на ноль"); None } else { Some(a / b) },
            op => { println!("Неизвестная операция: {}", op); None }
        };

        if let Some(r) = result {
            println!("= {}", r);
        }
    }
    println!("До свидания!");
}
```

```rust
        }
        let line = line.trim().to_string();

        if line == "выход" { break; }
        else if line == "список" {
            if tasks.is_empty() {
                println!("Задач нет.");
            } else {
                for (i, task) in tasks.iter().enumerate() {
                    println!("{}. {}", i + 1, task);
                }
            }
        }
        else if let Some(rest) = line.strip_prefix("удалить ") {
            if let Ok(idx) = rest.parse::<usize>() {
                if idx >= 1 && idx <= tasks.len() {
                    tasks.remove(idx - 1);
                    println!("Удалено.");
                } else {
                    println!("Нет такой задачи.");
                }
            }
        }
        else if line.starts_with("задача ") {
            tasks.push(line[7..].to_string());
            println!("Добавлено.");
        }
        else {
            println!("Не понял. Команды: 'задача текст', 'список', 'удалить N', 'выход'");
        }
    }
}
```

### Проект 3: Словарь частот (HashMap)

Посчитай частоту слов в тексте и выведи топ.

```rust
use std::collections::HashMap;

fn main() {
    let text = "the quick brown fox jumps over the lazy dog the end";
    let mut freq: HashMap<&str, u32> = HashMap::new();
    for word in text.split_whitespace() {
        *freq.entry(word).or_insert(0) += 1;
    }

    let mut pairs: Vec<(&str, u32)> = freq.into_iter().collect();
    pairs.sort_by(|a, b| b.1.cmp(&a.1));   // сортировка по убыванию частоты

    for (word, count) in &pairs {
        println!("{}: {}", word, count);
    }
}
```

### Проект 4: Структура-матрица

`struct Matrix { rows: usize, cols: usize, data: Vec<f64> }` с методами для создания,
доступа и сложения.

```rust
struct Matrix {
    rows: usize,
    cols: usize,
    data: Vec<f64>,
}

impl Matrix {
    fn zeros(rows: usize, cols: usize) -> Matrix {
        Matrix { rows, cols, data: vec![0.0; rows * cols] }
    }

    fn get(&self, r: usize, c: usize) -> f64 {
        self.data[r * self.cols + c]
    }

    fn set(&mut self, r: usize, c: usize, v: f64) {
        self.data[r * self.cols + c] = v;
    }

    fn add(&self, other: &Matrix) -> Option<Matrix> {
        if self.rows != other.rows || self.cols != other.cols {
            return None;
        }
        let mut res = Matrix::zeros(self.rows, self.cols);
        for i in 0..self.data.len() {
            res.data[i] = self.data[i] + other.data[i];
        }
        Some(res)
    }
}

fn main() {
    let mut a = Matrix::zeros(2, 2);
    a.set(0, 0, 1.0); a.set(1, 1, 1.0);
    let mut b = Matrix::zeros(2, 2);
    b.set(0, 1, 2.0); b.set(1, 0, 3.0);

    if let Some(c) = a.add(&b) {
        println!("{:?} {:?}", c.get(0, 0), c.get(1, 1));
        println!("сумма диагонали = {}", c.get(0,0) + c.get(1,1));
    }
}
```

### Проект 5: Мини-игра «Угадай число»

```rust
use std::cmp::Ordering;
use std::io::{self, Write};
use std::process;

fn main() {
    let secret = 42;  // в реальной игре — random
    println!("Угадай число от 1 до 100!");

    for attempt in 1..=10 {
        print!("Попытка {}: ", attempt);
        io::stdout().flush().unwrap();

        let mut guess = String::new();
        io::stdin().read_line(&mut guess).unwrap();
        let guess: i32 = match guess.trim().parse() {
            Ok(n) => n,
            Err(_) => { println!("Введи число!"); continue; }
        };

        match guess.cmp(&secret) {
            Ordering::Less => println!("Больше!"),
            Ordering::Greater => println!("Меньше!"),
            Ordering::Equal => {
                println!("Поздравляю! За {} попыток.", attempt);
                process::exit(0);
            }
        }
    }
    println!("Попытки закончились. Было: {}", secret);
}
```
