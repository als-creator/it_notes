## Установка и запуск

### Теория

Python — **интерпретируемый** язык: компьютер исходный код не компилируется в отдельный
бинарник заранее (в старые времена так было, сегодня есть нюансы с байт-кодом, но для
новичка суть та же) — интерпретатор читает и выполняет код **построчно** в момент запуска.
Это даёт мгновенный цикл разработки: изменил строку — перезапустил — увидел результат,
без долгой сборки.

Есть несколько понятий, которые полезно знать:

- **REPL** (Read-Eval-Print-Loop) — интерактивная среда, где можно вводить код по одной
  строке и сразу видеть результат. Запускается командой `python`.
- **`.py`-файл** — обычный текстовый файл с исходным кодом, запускается `python файл.py`.
- **виртуальное окружение** — изолированное пространство с собственными пакетами
  (о нём подробнее в отдельном разделе).

### ASCII-схема: как Python-интерпретатор выполняет код

```
  main.py (исходный код)
        |
        v
+------------------------------------------+
|  ИНТЕРПРЕТАТОР CPython                    |
|  1) читает строку                         |
|  2) разбирает её (компиляция в байт-код)  |
|  3) выполняет байт-код                    |
|  4) возвращается к шагу 1                 |
+------------------------------------------+
        |
        v
   результат на экране
```

Ошибка (например `NameError`) прерывает выполнение именно той строки, на которой
встретилась, — остальные строки уже выполнены.

Посмотрите на разбор команды `python script.py`:

```
$ python script.py
  │
  ├─ 1. Загружается интерпретатор CPython (ядро языка, написанное на C)
  ├─ 2. Читается файл script.py как текст
  ├─ 3. Текст разбирается парсером в дерево команд (анализ синтаксиса)
  ├─ 4. Дерево "компилируется" в байткод — компактные машинные инструкции PVM
  │     (результат кешируется в __pycache__/script.cpython-314.pyc,
  │      поэтому повторный запуск быстрее)
  ├─ 5. Виртуальная машина Python выполняет байткод построчно
  └─ 6. Результат печатается в терминал, программа завершается
```

Типы «ошибок» видны сразу:

- **SyntaxError** — парсер не понял текст (опечатка в конструкции).
- **NameError / TypeError / …** — обнаружены уже при исполнении байткода.

### Интерактивный режим

Пока вы учитесь, удобно не создавать файлы, а общаться с Python вживую. Запустите:

```bash
python
```

Появится приглашение `>>>` — это **REPL** (Read-Eval-Print Loop): Python читает вашу строку, выполняет её и печатает результат.

```python
>>> 2 + 2
4
>>> print("Привет!")
Привет!
>>> exit()
```

Совет: интерактивный режим — отличная «калькуляторная доска», там можно проверять любые однострочные примеры из этого учебника.

### Файлы .py и shebang

Если вы хотите запускать скрипт как обычную программу (без указания `python` перед именем), положите в первую строку **shebang** и сделайте файл исполняемым:

```python
#!/usr/bin/env python3
print("Привет из исполняемого скрипта!")
```

Затем:

```bash
chmod +x hello.py
./hello.py
```

`#!/usr/bin/env python3` означает: «найди в системе интерпретатор python3 и запусти этот файл им». В Windows shebang игнорируется — там хватает двойного клика по `.py` или команды `python hello.py`.

### Попробуй сам

Убедитесь, что Python установлен. В терминале (Linux/macOS) или командной строке (Windows):

```bash
python3 --version
```

Должно вывести что-то вроде `Python 3.13.1`.

Создайте файл `hello.py`:

```python
# hello.py — первая программа
print("Привет, мир!")
```

Запустите:

```bash
python3 hello.py
```

А теперь поработайте с REPL прямо в терминале:

```text
$ python3
>>> 2 + 2
4
>>> print("Python 3 — это работает!")
Python 3 — это работает!
>>> exit()
```

## Переменные и типы

### Теория

Переменная — это имя, ссылающееся на объект в памяти. Python — **динамически
типизированный** язык: тип переменной определяется значением, которое в неё попали,
и может меняться в процессе работы.

Основные встроенные типы:

- `int` — целые числа (нет ограничения на размер!)
- `float` — числа с плавающей точкой
- `str` — строка
- `bool` — `True`/`False`
- `NoneType` — специальный тип со значением `None` («ничего»)
- `list`, `tuple`, `dict`, `set` — составные структуры (в следующем разделе)

Функция `type(x)` показывает тип объекта, `id(x)` — адрес в памяти (занимает объект).

### ASCII-схема: типы данных

```
ПЕРЕМЕННАЯ = имя -> ссылка на объект
  name  --->  "Анна"          <class 'str'>
  age   --->  30              <class 'int'>
  pi    --->  3.14159         <class 'float'>
  ok    --->  True            <class 'bool'>
  nothing ---> None           <class 'NoneType'>

В памяти каждый объект хранит: тип + значение + счётчик ссылок.
```

### Попробуй сам

```python
# Переменные — присваивание создаёт ссылку на объект
name = "Анна"
age = 30
pi = 3.14159
is_happy = True
nothing = None

print(name, age, pi, is_happy, nothing)

# Тип выводится автоматически
print("name  →", type(name))
print("age   →", type(age))
print("pi    →", type(pi))
print("is_happy →", type(is_happy))

# Динамическая типизация: переменная может «поменять» тип
x = 10          # сейчас int
x = "десять"    # стала str
print(x, type(x))

# Динамическая типизация, но дальше — ошибка, если смешивать несовместимое
# print("число " + 10)  # TypeError: cannot concatenate
```

### Задание

1. Создайте переменную `my_city` со значением вашего города и выведите `type(my_city)`.
2. Создайте `temperature = 18.5` и выведите её тип.
3. Что выведет `type(type(42))`? Разберитесь.
4. Присвойте переменной одно значение, затем другое — проверьте, что тип «поменялся».
5. Чем `None` отличается от `0`?

### Самопроверка

**Ответы:**

1. `my_city = "Москва"`; `type(my_city)` → `<class 'str'>`.
2. `type(18.5)` → `<class 'float'>`.
3. `type(type(42))` → `<class 'type'>`. `type(42)` — это объект класса `type`, поэтому
   его тип — `type`.
4. Например: `v = 1` → тип `int`; `v = "hello"` → тип `str`. Python разрешает
   это, потому что тип определяется временным значением.

   значение. `None` можно сравнить только с самим собой (обычно через `is None`).

## Числа и строки

### Теория

**Числа.** Python поддерживает целые `int` (произвольной длины) и дробные `float`.
Арифметические операторы:

- `+`, `-`, `*`, `/` — обычные операции
- `//` — целочисленное деление (остаток отбрасывается вниз)
- `%` — остаток от деления
- `**` — возведение в степень

**Строки.** `str` — неизменяемая последовательность символов Unicode. Можно создавать
в одинарных `'...'`, двойных `"..."` и тройных `'''...'''` кавычках (для многострочного
текста). Строки поддерживают срезы `s[i:j]`, конкатенацию `+`, повторение `*`,
и методы для обработки (`.upper()`, `.split()`, `.strip()` и др.).

Современное форматирование — через **f-строки** (Python 3.6+): они читаются и
подставляют значения прямо в текст.

### ASCII-схема: строка как последовательность символов

```
  s = "привет"
  индекс:  0  1  2  3  4  5
           п  р  и  в  е  т
   отрицательные индексы (с конца):
           -6 -5 -4 -3 -2 -1

  s[0]  -> "п"
  s[-1] -> "т"
  s[1:4] -> "рив"
  СТРОКИ НЕИЗМЕНЯЕМЫ ОДИНАКОВО: нельзя присвоить s[2] = "я".
```

### Попробуй сам

```python
# Числа
a = 17
b = 5
print("Сумма:", a + b)          # 22
print("Деление:", a / b)        # 3.4 (обычное деление всегда даёт float)
print("Целочисленное деление:", a // b)  # 3
print("Остаток:", a % b)        # 2
print("Степень:", 2 ** 10)      # 1024

# Строки
city = "Санкт-Петербург"
print("Длина:", len(city))
print("Верхний регистр:", city.upper())
print("Срез [0:5]:", city[0:5])

# f-строки — современный способ форматирования
name = "Анна"
age = 30
greeting = f"Меня зовут {name}, мне {age} лет."
print(greeting)

# f-строка может содержать выражения
print(f"Через год: {age + 1} лет")

# Основные методы строк
text = "  Hello, world!  "
print(text.strip())             # 'Hello, world!'   — убрать пробелы по краям
print(text.lower().upper())     # регистр
print(text.replace("world", "Python"))   # 'Hello, Python!'
print(text.startswith("Hello")) # True
print(text.endswith("!"))       # True
print(text.find("world"))       # 8  — индекс первого вхождения или -1

# find vs index: find возвращает -1, index бросает исключение
text.find("такого слова")    # -1
# text.index("такого слова") # ValueError!

# split и join — самая популярная связка
sentence = "один,два,три"
parts = sentence.split(",")     # ['один', 'два', 'три']  — разбить по разделителю
restored = "-".join(parts)      # 'один-два-три'          — соединить через разделитель
words = "Hello world".split()   # по пробелам по умолчанию: ['Hello', 'world']

# Строки неизменяемы: каждый метод возвращает НОВУЮ строку
s = "Hi"
s.upper()
print(s)   # "Hi" — исходник не изменился!
```

### Задание

1. Вычислите `10 / 4`, `10 // 4`, `10 % 4` — объясните разницу.
2. Создайте строку с вашим именем и выведите её в верхнем и нижнем регистре.
3. Выведите только чётные цифры из строки `"123456789"` (срез с шагом).
4. Используйте f-строку: выведите таблицу умножения, например `5 x 3 = 15`.
5. Объясните, почему `"a" + "b"` даёт `"ab"`, а `"5" + "3"` — `"53"`, а не `8`.

### Самопроверка

**Ответы:**

1. `10 / 4 = 2.5`, `10 // 4 = 2`, `10 % 4 = 2`. Обычное деление даёт плавающую точку,
   `//` отбрасывает дробную часть (округляет вниз), `%` возвращает остаток.
2. `name = "анна"` → `name.upper()` → `"АННА"`, `name.lower()` → `"анна"`.
3. `"123456789"[1::2]` — с индекса 1 с шагом 2 → `"2468"`.
4. `print(f"5 x 3 = {5 * 3}")` → `5 x 3 = 15`.
5. Строки при конкатенации просто склеиваются. `"5" + "3"` — это две строки,
   поэтому результат — `"53"` (строка). Чтобы получить число 8, нужно сначала
   конвертировать: `int("5") + int("3")`.

## Списки, кортежи, множества, словари

### Теория

Четыре основные составные структуры данных:

- **list** `[1, 2, 3]` — изменяемая, упорядоченная последовательность. Можно добавлять,
  удалять, менять элементы.
- **tuple** `(1, 2, 3)` — неизменяемая последовательность. Быстрая, защищена от случайной
  модификации. Часто используют для нескольких возвращаемых значений.
- **set** `{1, 2, 3}` — неупорядоченное множество уникальных элементов. Быстрые проверки
  принадлежности и операции множеств.
- **dict** `{"ключ": значение}` — словарь, таблица «ключ → значение». Быстрый доступ
  по ключу.

### ASCII-схема: структуры данных

```
LIST  [1, 2, 3]          упорядочен, МОЖНО менять
TUPLE (1, 2, 3)          упорядочен, НЕЛЬЗЯ менять
SET   {1, 2, 3}          НЕупорядочен, только уникальные, быстрый поиск
DICT  {"ключ": значение} <--->  быстрый доступ по ключу (хеш-таблица)

DICT
+---------+--------+
|  "alpha"|  1     |
|  "beta" |  2     |
+---------+--------+
d["alpha"] -> 1
```

**Когда кортеж нужен:** координаты, год/месяц/день, строки, которые переиспользуются как ключи словаря (кортежи можно хешировать, списки — нет).

```python
coords = (10, 20)
x, y = coords          # распаковка
print(x, y)            # 10 20
# coords[0] = 15  -> TypeError: 'tuple' object does not support item assignment
```

**Операции множеств:**

```python
a = {1, 2, 3}
b = {3, 4, 5}
print(a | b)   # объединение:  {1, 2, 3, 4, 5}
print(a & b)   # пересечение:  {3}
print(a - b)   # разность:     {1, 2}
```

**Безопасный доступ через `.get()`:**

```python
user = {"login": "neo", "role": "admin"}
# user["age"]  -> KeyError, программа упадёт!
print(user.get("age"))            # None — безопасно
print(user.get("age", 18))        # 18 — значение по умолчанию
```

### Коллекции из collections: defaultdict, Counter, OrderedDict

Стандартный модуль `collections` даёт «прокачанные» контейнеры.

**`defaultdict`** — словарь, который не бросает `KeyError`, а сам создаёт значение по умолчанию. Классика — подсчёт и группировка:

```python
from collections import defaultdict

scores = defaultdict(int)      # по умолчанию вернётся 0
scores["кот"] += 1
scores["кот"] += 1
print(scores["кот"])           # 2
print(scores["пёс"])           # 0 — ключа не было, но и ошибки нет

by_city = defaultdict(list)    # по умолчанию пустой список
by_city["Москва"].append("Аня")
by_city["Москва"].append("Боря")
print(by_city["Москва"])       # ['Аня', 'Боря']
```

**`Counter`** — готовый счётчик элементов:

```python
from collections import Counter

colors = ["red", "blue", "red", "green", "red", "blue"]
c = Counter(colors)
print(c)                 # Counter({'red': 3, 'blue': 2, 'green': 1})
print(c.most_common(1))  # [('red', 3)] — самое частое
```

**`OrderedDict`** — словарь, помнящий порядок вставки. С Python 3.7 обычный `dict` тоже сохраняет порядок, поэтому `OrderedDict` нужен редко — в основном для совместимости и методов `move_to_end`/`popitem(last=...)`:

```python
from collections import OrderedDict

od = OrderedDict()
od["a"] = 1
od["b"] = 2
od.move_to_end("a")      # переместить ключ в конец
print(list(od))          # ['b', 'a']
```

### Попробуй сам

```python
# СПИСОК — изменяемый
numbers = [3, 1, 2]
numbers.append(4)        # добавить в конец
numbers.sort()           # отсортировать на месте
print("Список:", numbers)

# ТУПЛ — неизменяемый
point = (10, 20)
print("Кортеж:", point)
x, y = point             # распаковка
print("x =", x, "y =", y)

# МНОЖЕСТВО — уникальные элементы
fruits = {"яблоко", "банан", "яблоко"}  # дубликат исчезнет
print("Множество:", fruits)

# СЛОВАРЬ — ключ: значение
person = {
    "имя": "Анна",
    "возраст": 30,
    "город": "Москва",
}
print("Имя:", person["имя"])

# Добавление и изменение значений в словаре
person["телефон"] = "+7-900-000-00-00"   # добавить
person["возраст"] = 31                    # изменить
print("Словарь:", person)

# Перебор словаря
for key, value in person.items():
    print(f"{key}: {value}")
```

### Методы списков

```python
lst = [1, 2, 3]

lst.append(4)            # добавить в конец: [1, 2, 3, 4]
lst.extend([5, 6])       # добавить несколько: [1, 2, 3, 4, 5, 6]
lst.insert(0, 0)         # вставить по индексу: [0, 1, 2, ...]
lst.pop()                # удалить и вернуть последний элемент
lst.pop(0)               # удалить и вернуть элемент по индексу
lst.remove(3)            # удалить первое вхождение по значению
lst.index(2)             # индекс элемента (или ValueError)
lst.count(2)             # сколько раз встречается
lst.sort()               # отсортировать на месте
sorted_list = sorted(lst)  # отсортировать, вернув новую копию
lst.reverse()            # развернуть на месте
lst.copy()               # копия
```

### Списковые включения

**List comprehension** — компактный способ построить список из любого цикла:

```python
squares = [x ** 2 for x in range(10)]          # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
evens = [x for x in range(20) if x % 2 == 0]   # только чётные
words = [w.upper() for w in ["a", "bb"] if len(w) > 1]  # ['BB']
```

Тот же цикл без включения занимал бы в 3-5 раз больше строк — это самый «питонический» приём для фильтрации и преобразования данных.

### Изменяемые и неизменяемые типы

Это ключевое понятие. **Неизменяемые** объекты нельзя поменять — любая операция создаёт новый объект. **Изменяемые** — можно модифицировать «на месте».

```
               ВСТРОЕННЫЕ ТИПЫ
     ┌────────────────────────────────────────────┐
     │  НЕИЗМЕНЯЕМЫЕ (immutable)                  │
     │  int  float  str  bool  None  tuple  frozenset │
     │  ────────────────────────────────────────── │
     │  переприсваивание создаёт НОВЫЙ объект      │
     └────────────────────────────────────────────┘
     ┌────────────────────────────────────────────┐
     │  ИЗМЕНЯЕМЫЕ (mutable)                      │
     │  list  dict  set                            │
     │  ────────────────────────────────────────── │
     │  объект можно менять на месте, не плодя    │
     │  новые объекты (append, pop, d[key]=v ...)  │
     └────────────────────────────────────────────┘
```

Практическая разница:

```python
s = "abc"
# s[0] = "X"  -> ОШИБКА TypeError: 'str' object does not support item assignment

lst = [1, 2, 3]
lst.append(4)      # меням на месте
print(lst)         # [1, 2, 3, 4]
```

Из-за изменяемости есть подводный камень с копированием списков:

```python
a = [1, 2, 3]
b = a          # b и a указывают на ОДИН и тот же список!
b.append(99)
print(a)       # [1, 2, 3, 99]  — "a" тоже изменился!

c = a.copy()   # настоящая копия
c.append(7)
print(a)       # [1, 2, 3, 99]  — "a" не тронут
```

### Приведение типов

Складывать строку и число напрямую нельзя (будет `TypeError`). Типы приводят явно:

```python
a = "10"
b = 5

print(int(a) + b)   # 15 (число)
print(a + str(b))   # "105" (строка, конкатенация)
print(float(b))     # 5.0
print(str(True))    # "True"
```

## Условия и циклы

### Теория

**Условия.** Конструкция `if`/`elif`/`else` позволяет выполнить код в зависимости от
условия. В Python нет `switch`; вместо него (начиная с 3.10) есть структурное
сопоставление **`match`**.

```python
if условие:
    ...
elif другое_условие:
    ...
else:
    ...
```

**Циклы.** Два вида:

- `for` — перебор по последовательности (список, строка, диапазон `range`).
- `while` — выполняется, пока верно условие.

Служебные слова `break` (выйти из цикла) и `continue` (перейти к следующей итерации).

**`else`** после цикла — срабатывает, если цикл завершился **без** `break`:

```python
for num in range(10):
    if num == 7:
        break
else:
    print("Семёрка не встретилась")
```

**Тернарный оператор** (условие в одну строку):

```python
status = "взрослый" if age >= 18 else "ребёнок"
```

**Частая ошибка новичков:**

```python
code = 2
# if code == 1 or 2 or 3:  — всегда True! (2 трактуется как истина)
# Правильно:
if code in [1, 2, 3]:
    print("Код подходит")
```

**`match`** — структурное сопоставление: может разбирать не только значения, но и
структуры (списки, кортежи, словари, классы).

### ASCII-схема: цикл for

```
  for element in [1, 2, 3]:

  [ старт ]
      |
      v
  есть следующий элемент?
     /   \
    да     нет
    |        |
    v        v
  выполнить тело   [ конец ]
    |
    v
  (вернуться к проверке)
```

## Функции и lambda

### Теория

**Функция** — именованный блок кода с параметрами и результатом. Объявляется через `def`.
Функция может:

- принимать параметры (в том числе со значениями по умолчанию, именованные — `*args`, `**kwargs`);
- возвращать значение через `return` (или ничего — тогда возвращает `None`);
- иметь документацию (docstring).

**lambda** — анонимная мини-функция из одного выражения:

```python
функция = lambda аргументы: выражение
```

`map`/`filter` вместе с lambda — классика функционального стиля, хотя современный Python
предпочитает генераторы списков. В разделе про генераторы мы это увидим.

### ASCII-схема: функция

```
   [ вызов ]  result = add(3, 7)
       |
       v
  +---------------+     параметры: 3, 7
  | def add(a, b) |  -> return a + b  -> 10
  +---------------+
       |
       v
   вызывающий код получает 10
```

### Попробуй сам

```python
# Обычная функция
def greet(name: str, greeting: str = "Привет") -> str:
    """Выводит приветствие."""
    return f"{greeting}, {name}!"

print(greet("Анна"))
print(greet("Пётр", "Добрый день"))

# Параметры по умолчанию и именованные
def make_profile(name, city="Не указан", age=None):
    return {"имя": name, "город": city, "возраст": age}

print(make_profile("Иван", age=28))

# lambda — анонимная функция
double = lambda x: x * 2
print("double(21):", double(21))

# lambda с map и filter
numbers = [1, 2, 3, 4, 5, 6]
squared = list(map(lambda x: x * x, numbers))
even = list(filter(lambda x: x % 2 == 0, numbers))
print("Квадраты:", squared)
print("Чётные:", even)

# Функция, принимающая другую функцию
def apply_twice(func, value):
    return func(func(value))

print("apply_twice(double, 5):", apply_twice(double, 5))
```

### Области видимости: LEGB

Python ищет имена в строгом порядке:

```
L — Local      (локальные имена внутри текущей функции)
E — Enclosing  (имена во внешних (вложенных) функциях)
G — Global     (глобальные имена модуля)
B — Built-in   (встроенные имена Python: print, len, ...)
```

```
            ┌───────────────────────────────┐
            │  B  Built-in: print, len, ... │  ← самый внешний
            │      ┌─────────────────────┐  │
            │      │  G  Global (модуль) │  │
            │      │   │  ┌───────────┐  │  │
            │      │   │  │ E Enclosing│  │  │
            │      │   │  │   │  ┌─────┐│  │  │
            │      │   │  │   │  │ L   ││  │  │  ← самый внутренний
            │      │   │  │   │  └─────┘│  │  │     (текущая функция)
            │      │   │  └───────────┘  │  │
            │      └─────────────────────┘  │
            └───────────────────────────────┘
   поиск идёт изнутри наружу: сначала L, потом E, G, B
```

```python
x = 10                      # G

def outer():
    y = 20                  # E (для inner)
    def inner():
        z = 30              # L
        print(x, y, z)      # ищет: L -> E -> G -> B
    inner()

outer()                     # 10 20 30
```

Ключевое слово `global` позволяет менять глобальную переменную из функции — но его разумнее **не использовать**. Передавайте данные через аргументы, результат — через `return`.

Аннотации типов (тайп-хинтинг) — не обязательны, но поднимают читаемость кода и помогают IDE ловить ошибки:

```python
def add_numbers(a: int, b: int) -> int:
    return a + b
```

### Стек вызовов

Когда функция вызывает другую функцию, Python складывает активные вызовы «стопкой» и выполняет их строго по порядку: последний вызванный заканчивается первым (LIFO — Last In, First Out):

```
        main()                 main()
        │                      │
        │   greet("Ира")  →   │   greet()
        │                      │    │
        │                      │    │  format_name()  →   ┌───────┐
        │                      │    │                     │ ...   │ ← верх стека:
        │                      │    │                     └───────┘   выполняется сейчас
        │                      │    │
        │                      │  format_name() завершена (вернула "Ира!")
        │                      │   └── результат попал в greet()
        │                   greet() завершена
        │                        └── print выполнил вывод
     main() завершилась → программа выходит
```

Ошибка `RecursionError` — сигнал того, что стек вызовов переполнился: функция вызывает саму себя без условия выхода (бесконечная рекурсия). Отладочную распечатку стека даёт traceback при исключении — читайте его снизу вверх: сначала указывается место аварии, ниже — цепочка вызвавших функций.

```python
def main():
    greet("Ира")          # 1) main -> greet

def greet(name):
    full = format_name(name)   # 2) greet -> format_name
    print("Привет,", full)     # 4) снова в greet

def format_name(n):
    return n + "!"             # 3) format_name (верх стека)

main()                    # Привет, Ира!
```

## Модули и импорт

### Теория

Программа любого размера > одного файла разбивается на **модули**. Модуль — это
файл с расширением `.py`. Его подключают через `import`.

Способы подключения:

- `import math` — импорт всего модуля; обращение через `math.pi`.
- `from math import sqrt` — импорт конкретного имени.
- `import math as m` — псевдоним.

Стандартная библиотека Python огромна: `math`, `random`, `datetime`, `os`,
`pathlib`, `json`, `collections`, `itertools` и сотни других. Сторонние пакеты
устанавливаются через `pip` и хранятся в виртуальном окружении.

Файл `__name__ == "__main__"` защищает код от запуска при импорте.

### ASCII-схема: порядок поиска модуля

```
   import math
        |
        v
  +-------------------------+
  | 1. ищет в sys.path:      |
  |    - папка текущего файла|
  |    - PYTHONPATH          |
  |    - папки site-packages |
  +-------------------------+
        |
        v
  модуль найден -> выполняет код модуля -> объект math (кэшируется)
  повторный import не перечитывает файл
```

Как Python находит модули? Список директорий, которые просматриваются при `import`, — в `sys.path`:

```python
import sys
print(sys.path)
# ['', '/usr/lib/python3.14', '/usr/lib/python3.14/lib-dynload',
#  '/home/als/.local/lib/python3.14/site-packages', ...]
```

Первым в списке обычно стоит пустая строка — текущая директория. Поэтому локальный файл `my_module.py` можно импортировать просто `import my_module`.

**Пакет** — это директория с файлом `__init__.py` (в современных версиях он может быть необязателен, но по традиции его создают):

```
mypackage/
├── __init__.py
├── utils.py
└── models.py
```

```python
from mypackage.utils import some_function
```

## Работа с файлами и pathlib

### Теория

Запись и чтение файлов — одна из самых частых задач. В Python есть два основных подхода:

1. **Классические встроенные функции** `open()` + методы файла.
2. **Современный объектно-ориентированный подход** через `pathlib.Path` — рекомендуется
   для новых программ.

Современная идиома — контекст-менеджер `with`, который автоматически закрывает файл
даже при ошибке.

Объект `Path` красиво работает с путями: не нужно склеивать строки и символы разделителей.

### ASCII-схема: чтение и запись

```
ПРОГРАММА                          ФАЙЛ на диске
+-------------+   открытие   +------------------+
| with open(  | -----------> |  данные          |
|  "notes.txt")|             +------------------+
|  ... читаем/|   закрытие   |
|  пишем      | <----------- |   (with закроет сам)
+-------------+
```

### Попробуй сам

```python
from pathlib import Path

# ПУТЬ как объект
home = Path("./data")
home.mkdir(exist_ok=True)              # создать папку, если её нет
notes_path = home / "notes.txt"        # компоновать путь как «папка / файл»

# ЗАПИСЬ (перезаписать файл)
with notes_path.open("w", encoding="utf-8") as f:
    f.write("Строка 1\nСтрока 2\n")

# ДОЗАПИСЬ (режим "a" — append)
with notes_path.open("a", encoding="utf-8") as f:
    f.write("Строка 3\n")

# ЧТЕНИЕ целиком
content = notes_path.read_text(encoding="utf-8")
print("Содержимое:\n", content)

# Построчное чтение
for line in notes_path.read_text(encoding="utf-8").splitlines():
    print("Строка:", line)

# Проверки: существует ли файл, его размер
print("Файл существует:", notes_path.exists())
print("Размер в байтах:", notes_path.stat().st_size)
```

Ещё пример классического `open()`:

```python
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("Hello\n")
```

Режимы открытия:

| Режим | Действие |
| --- | --- |
| `'r'` | чтение (по умолчанию) |
| `'w'` | запись — **стерев** существующее содержимое; создаст, если нет |
| `'a'` | дописывание в конец файла |
| `'rb'` / `'wb'` | чтение/запись в **бинарном** режиме (картинки и т.п.) |

`encoding="utf-8"` — обязателен при работе с русским текстом на Windows, иначе будут «кракозябры».

```python
# json: сохранить словарь в файл и прочитать обратно
import json

data = {"name": "Аня", "active": True, "skills": ["Python", "Git"]}

with open("user.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open("user.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)    # снова словарь

print(loaded["name"])
```

## Работа с ошибками (try/except)

### Теория

Python сообщает об ошибках с помощью **исключений** (exceptions). Когда возникает ошибка,
интерпретатор «выбрасывает» объект-исключение, прерывая выполнение. Чтобы обработать
ошибку программно, используют блок `try`/`except`.

```python
try:
    рискованный_код()
except КонкретнаяОшибка as e:
    обработать(e)
else:
    код_который_выполнится_если_ошибки_нет()
finally:
    код_который_выполнится_всегда()
```

Важно перехватывать **конкретные** типы исключений, а не голый `except:`.

### ASCII-схема: поток исключения

```
   try-блок
      |
      v
  возникает исключение?  --нет-->  else-блок (выполнится)
      | да
      v
  ищем подходящий except
      |            |
   найден      не найден
      |            |
      v            v
 обработка     исключение летит выше,
 (программа    программа падает
  продолжается)
      ^
      |
  finally-блок выполняется ВСЕГДА (очистка, закрытие)
```

### Попробуй сам

```python
def safe_divide(a, b):
    """Безопасное деление с обработкой ошибок."""
    try:
        result = a / b
    except ZeroDivisionError:
        print("Ошибка: деление на ноль!")
        return None
    except TypeError as e:
        print(f"Ошибка типов: {e}")
        return None
    else:
        # Выполняется, только если в try не было исключения
        print("Деление успешно")
        return result
    finally:
        # Выполняется ВСЕГДА: и при успехе, и при ошибке
        print("finally: завершаем")

print(safe_divide(10, 2))
print(safe_divide(10, 0))
print(safe_divide("10", 2))

# Выбросить своё исключение
def check_age(age):
    if age < 0:
        raise ValueError("Возраст не может быть отрицательным")
    return age

try:
    check_age(-5)
except ValueError as err:
    print("Поймали:", err)
```

**Не пишите «голый» `except:`** — это скрывает баги и даже глушит `Ctrl+C`:

```python
# ПЛОХО:
try:
    risky_stuff()
except:
    print("Что-то пошло не так")

# ХОРОШО:
try:
    risky_stuff()
except (ValueError, KeyError) as e:
    print(f"Ожидаемая ошибка: {e}")
```

Правило: перехватывайте только ожидаемые конкретные ошибки (`ValueError`, `IndexError`, `KeyError`, `ZeroDivisionError`, `FileNotFoundError`, ...). Всё остальное обязано «упасть», чтобы вы увидели баг.

**Иерархия встроенных исключений** растёт из `Exception`, а он — из `BaseException`:

```
BaseException
 └── Exception
     ├── ArithmeticError
     │   └── ZeroDivisionError
     ├── LookupError
     │   ├── IndexError
     │   └── KeyError
     ├── ValueError
     ├── TypeError
     ├── FileNotFoundError   (входит в OSError)
     └── ...
```

## Генераторы

### Теория

**Генератор** — функция, возвращающая последовательность значений лениво, по одному
за раз, вместо возврата всего списка сразу. Ключевое слово — `yield` (вместо `return`).

Польза:

- Экономия памяти (не создавать гигантские списки целиком).
- Ленивые вычисления: значения производятся только когда нужны.
- Удобная обработка бесконечных/потоковых данных.

Генераторные выражения похожи на списковые включения, но с круглыми скобками:

```python
gen = (x * x for x in range(5))
```

### ASCII-схема: ленивость генератора

```
Обычная функция:   return [1, 2, 3,   4,   5]      <- всё сразу в памяти
Генератор (yield):  1 -> 2 -> 3 -> 4 -> 5          <- по одному, по запросу
```

### Попробуй сам

```python
# Классический пример: числа Фибоначчи
def fibonacci(limit):
    a, b = 0, 1
    while a < limit:
        yield a                 # отдать текущее значение и «заморозиться»
        a, b = b, a + b

print("Фибоначчи до 50:")
for number in fibonacci(50):
    print(number, end=" ")
print()

# Генератор как ленивая последовательность
squares = (x * x for x in range(10))
print("Первые 3 квадрата:", next(squares), next(squares), next(squares))

# Генератор экономит память
import sys
big_list = [i for i in range(1000)]   # список держит всё в памяти
big_gen = (i for i in range(1000))    # генератор — по одному
print("Размер списка в байтах:", sys.getsizeof(big_list))
print("Размер генератора в байтах:", sys.getsizeof(big_gen))

# Генератор с суммой — классика
print("Сумма квадратов 0..9:", sum(x * x for x in range(10)))
```

**Ответы:**

4. `return` завершает функцию и отдаёт одно значение. `yield` приостанавливает функцию,

5. Когда значения кончились, `next(g)` выбрасывает `StopIteration`. В `for`-цикле

## ООП базово

### Теория

**Объектно-ориентированное программирование (ООП)** — подход, при котором данные и
функции над ними объединяются в **классы** и **объекты**.

Ключевые понятия:

- **Класс** — «чертёж» объекта: описывает поля (данные) и методы (поведение).
- **Объект (экземпляр)** — конкретный «продукт» по чертежу.
- **`__init__`** — конструктор, вызывается при создании объекта.
- **`self`** — ссылка на конкретный экземпляр (первый параметр методов).
- **Наследование** — класс может взять всё от другого класса и расширить.
- **`__str__` / `__repr__`** — строковое представление объекта.

### ASCII-схема: класс как шаблон

```
КЛАСС  Cat                        КЛАСС Dog (наследует Animal)
+----------------+                +----------------+
| имя, возраст   |   экземпляры   | лает, ...      |
| мяукать()      |                +----------------+
+----------------+                       ^
      |                                  | наследование
      v
+------------------+
| Animal (зверь)   |
| имя, age, eat()  |
+------------------+
```

### Попробуй сам

```python
class Cat:
    """Класс, описывающий кота."""

    # Конструктор — вызывается при создании объекта
    def __init__(self, name: str, age: int):
        self.name = name      # поле экземпляра
        self.age = age
        self.hungry = True

    # Метод — поведение объекта
    def meow(self) -> str:
        return f"{self.name} говорит мяу!"

    def feed(self):
        self.hungry = False

    def __str__(self) -> str:
        return f"Cat({self.name}, {self.age} лет)"

# Создаём объекты (экземпляры)
mурka = Cat("Мурка", 3)
barsik = Cat("Барсик", 5)

print(mурka.meow())          # Мурка говорит мяу!
print(barsik.meow())

print(mурka)                 # вызовется __str__

print("Мурка голодная?", mурка.hungry)
mурka.feed()
print("После кормления:", mурka.hungry)


# Наследование
class Dog(Cat):
    """Собака — наследует всё от Cat (для примера)."""

    def bark(self):
        return f"{self.name} говорит гав!"

rex = Dog("Рекс", 4)
print(rex.meow())   # унаследованный метод от Cat
print(rex.bark())   # собачий метод
```

**Dunder-методы** (double underscore) — «переопределяем встроенное поведение». Краткий список самых полезных:

| Метод | Назначение |
| --- | --- |
| `__init__(self, ...)` | конструктор |
| `__str__(self)` | строковое представление для `print()` |
| `__repr__(self)` | представление для разработчика (repr) |
| `__len__(self)` | поддерживает `len(obj)` |
| `__getitem__(self, k)` | поддерживает `obj[k]` |
| `__eq__(self, other)` | поведение `==` |
| `__add__(self, other)` | поведение `+` |

Инкапсуляция в Python по соглашению: имя с одним подчёркиванием `_foo` — «внутреннее», с двумя `__foo` — придёт name-mangling (формальная «приватность»).

## Виртуальные окружения (venv/uv/Poetry)

### Теория

**Виртуальное окружение** — это изолированная «песочница», где можно устанавливать
пакеты для конкретного проекта, не засоряя системный Python. Для каждого проекта —
свой набор зависимостей, свои версии.

**Проблема:** у интерпретатора *одна* директория `site-packages`. Установили `requests==2.23.0` для проекта А — установка `requests==1.2.3` для проекта Б её перезатрёт. Два проекта с разными версиями одной библиотеки не могут жить в одном интерпретаторе, а дерево зависимостей при этом только всё усложняет.

**Решение:** у каждого проекта своя изолированная копия интерпретатора со своими пакетами — виртуальное окружение.

Варианты управления:

1. **`venv`** — встроенный инструмент: `python3 -m venv .venv`.
2. **`uv`** — современный суперскоростной менеджер окружений и пакетов (написан на Rust).
3. **`Poetry`** — популярный менеджер зависимостей с `pyproject.toml` и lock-файлом.

### ASCII-схема: изоляция окружений

```
СИСТЕМНЫЙ ПИТОН                     ПРОЕКТ (свой .venv)
+-----------------+                +-----------------------+
| пакеты global   |                | пакеты ТОЛЬКО этого   |
| не трогаем!     |                | проекта (напр. requests)|
+-----------------+                +-----------------------+
        ^                                  ^
        |  никак не влияют друг на друга   |
        +----------------------------------+
```

### Попробуй сам

**Вариант 1: venv (встроенный)**

```bash
# Linux/macOS
python3 -m venv .venv
source .venv/bin/activate      # активировать
pip install requests           # установка пакета ТОЛЬКО сюда
deactivate                     # выйти

# Windows
# .venv\Scripts\activate
```

**Вариант 2: uv (рекомендуемый современный)**

```bash
# установка uv: https://docs.astral.sh/uv/
uv init myproject
cd myproject
uv add requests
uv run python script.py        # запуск внутри окружения
```

**Вариант 3: Poetry**

```bash
poetry new myproject
cd myproject
poetry add requests
poetry run python script.py
```

Как проверить, что окружение активно, и посмотреть установленные пакеты:

```bash
pip list
```

Перед первым шагом посмотрите шпаргалку в заметках: [venv](/home/als/notes/venv.md) и [Виртуальные окружения Python](/home/als/notes/Виртуальные%20окружения%20Python.md).

**Правила:**

- никогда не ставьте зависимости проекта в *глобальный* интерпретатор;
- никогда не используйте `sudo pip` — это табу;
- системные утилиты вне окружений ставьте через `pip install --user` или пакетный менеджер ОС.

### Сравнение инструментов

| Инструмент | Что это | Особенности | Когда выбирать |
| --- | --- | --- | --- |
| `venv` | встроенный создатель окружений | только окружения, никакого менеджмента зависимостей | базовый минимум, есть в любом Python |
| `uv` | сверхбыстрый «швейцарский нож» (Rust) | окружения + пакеты + версии Python + lock-файл, один бинарник | новичок и профи: современный стандарт |
| `Poetry` | полноценный менеджер проекта | `pyproject.toml`, `poetry.lock`, dev/основные зависимости | разработка библиотек/публикуемых пакетов |
| `pipenv` | надстройка над pip + venv | `Pipfile` + `Pipfile.lock`, загрузка `.env` | проект «как приложение», легаси |

**uv** заменяет сразу цепочку: `pip` + `venv` + `pip-tools` + `poetry` + `pyenv` + `pipx`. Старт с ним простейший:

```bash
uv init my_app                 # новый проект: pyproject.toml, uv.lock, .venv
uv add requests                # добавить зависимость (окружение создастся само)
uv run python main.py          # запуск внутри окружения без активации
uv tree                        # дерево зависимостей
```

Установка uv (Linux/macOS): `curl -LsSf https://astral.sh/uv/install.sh | sh`

## Работа с сетью (requests)

### Теория

`requests` — самая популярная библиотека Python для работы с HTTP. Это сторонний пакет:
его устанавливают через `pip` (в виртуальном окружении) — он не входит в стандартную
библиотеку.

Основные возможности:

- `requests.get(url, params=...)` — GET-запрос с параметрами.
- `requests.post(url, json=...)` — POST-запрос с JSON-телом.
- `response.status_code` — код ответа (200 OK и т.д.).
- `response.text` — тело ответа как строка.
- `response.content` — тело ответа байтами (для скачивания файлов).
- `response.json()` — тело как объект Python (если пришёл JSON).
- `response.headers` — заголовки.
- `response.raise_for_status()` — бросит исключение, если код не 2xx/3xx.

### ASCII-схема: HTTP-запрос через requests

```
  Python-код                    Интренет            Сервер
  requests.get(url)   ------- запрос -------->    обрабатывает
  resp                                   <------  Ответ (шапка + тело)
  resp.status_code  -> 200
  resp.text         -> "<html>... " / JSON
```

### Попробуй сам

```python
import requests

# Простой GET-запрос
response = requests.get("https://httpbin.org/get")
print("Статус:", response.status_code)
print("Тело (первые 200 символов):", response.text[:200])

# GET с параметрами (нормально для REST API)
params = {"name": "Анна", "city": "Москва"}
response = requests.get("https://httpbin.org/get", params=params)
print("Отправили параметры; сервер их вернул в args:")
print(response.json().get("args"))

# Если сервер возвращает JSON — удобно через .json()
data = response.json()
print("Ключи ответа:", list(data.keys()))

# Проверка ошибок
bad = requests.get("https://httpbin.org/status/404")
print("Статус 404:", bad.status_code)
print("Хороший запрос?", bad.ok)   # False для 404

# POST с JSON
r = requests.post("https://api.example.com/message", json={"text": "Привет!"})

# Ответ как байты (для скачивания файлов)
r = requests.get("https://example.com/image.png")
with open("image.png", "wb") as f:
    f.write(r.content)

# Бросить исключение при неудачном HTTP-ответе
r = requests.get("https://httpbin.org/status/500")
r.raise_for_status()  # вызовет HTTPError для кодов 4xx/5xx
```

## Ввод-вывод CLI

### Теория

Программы для командной строки (CLI) читают данные из входного потока и выводят в
выходной. Основные инструменты:

- `print()` — вывод.
- `input(подсказка)` — чтение строки из консоли.
- `sys.argv` — аргументы командной строки.
- `argparse` — полноценный парсер аргументов (флаги, `--help`).
- `sys.stdin` / `sys.stdout` — стандартные потоки.

Для быстрых утилит достаточно `sys.argv` + `input()`. Для «хороших» CLI-программ —
`argparse` из стандартной библиотеки.

### ASCII-схема: потоки процесса

```
  запуск:  python3 app.py --mode fast
                     |
                     v
            +-----------------+
            |   sys.argv ==    |
            |  ["app.py","--mode","fast"] |
            +-----------------+
               | ввод         | вывод
               v              v
        stdin (консоль)   stdout (консоль)
```

### Попробуй сам

```python
import sys
import argparse

# ВАРИАНТ 1: простое чтение ввода
name = input("Введите ваше имя: ")
print(f"Привет, {name}!")

# ВАРИАНТ 2: аргументы через sys.argv
print("Скрипт:", sys.argv[0])
print("Аргументы:", sys.argv[1:])

# ВАРИАНТ 3: argparse для красивых CLI-программ
parser = argparse.ArgumentParser(description="Сложение двух чисел")
parser.add_argument("a", type=int, help="первое число")
parser.add_argument("b", type=int, help="второе число")
parser.add_argument("--verbose", action="store_true", help="подробный вывод")

args = parser.parse_args()

result = args.a + args.b
if args.verbose:
    print(f"{args.a} + {args.b} = {result}")
else:
    print(result)
```

Сохраните файл как `add.py` и запустите:

```bash
python3 add.py 3 4
python3 add.py 3 4 --verbose
python3 add.py --help
```
