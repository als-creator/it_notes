## С чего начать (план освоения)

Если вы видите Vim в первый раз — не пугайтесь кривой обучения. Пройдите по шагам:

1. **Пройдите встроенный `vimtutor`** (идёт вместе с Vim). Он проведёт вас по всем базовым командам.
   ```bash
   vimtutor
   ```
2. **Поиграйте в интерактивные тренажёры** (ссылки ниже) — учиться лучше сразу с практикой, играя.
3. **Начните работать по-настоящему**, но не разучивайтесь «как-нибудь». Не используйте стрелки и не избегайте командного режима — это худшая ошибка новичка.
4. **Распечатайте cheatsheet** и держите перед глазами.
5. **Возьмите готовую современную сборку** (LazyVim и др. — ссылки ниже) и сосредоточьтесь на самом Vim.
6. Не учите Vim **одновременно** с новым языком/фреймворком — когнитивная нагрузка будет огромной.

> Реалистичные сроки (по опыту): «любое действие занимает минуту» → «могу спокойно работать» ≈ **1 месяц**. Полное оттачивание — до года.

### Детальный процесс обучения (по гайду Hexlet)

1. **Поставьте nvim и vim** (nvim с поддержкой python3).
2. **Пройдите `vimtutor`** — официальный встроенный учебник, идёт в поставке.
3. **Распечатайте и изучите [vim cheatsheet](https://bit.ly/2urvrMA)**.
4. **Научитесь использовать возможности терминала** — сплиты и вкладки (горячие клавиши).
5. **Измените маппинги клавиш**: Caps Lock → Ctrl, выход из insert через `jj` или `Ctrl+[`.
6. **Дальше два пути:**
   - настроить свой `.vimrc` с нуля — сложно и затратно на первых порах;
   - **взять готовую сборку** (рекомендация Hexlet — [сборка mokevnin](https://github.com/mokevnin/dotfiles)) и сосредоточиться на владении самим Vim, постепенно разбираясь, как всё устроено внутри.
7. **Освойте менеджер плагинов [vim-plug](https://github.com/junegunn/vim-plug)** — с него начинается вход в мир плагинов.
8. **Изучение Vim = два аспекта:**
   - работа **внутри буфера** — навигация, базовые команды модификации и перемещения;
   - **навигация по проекту** — дерево файлов (NERDTree), нечёткий поиск (fzf), переключение буферов (bufexplorer), прыжки по последним модификациям, `gf` (go to file).
9. **Установите плагины под ваш стек** — предпочтение плагинам на основе **[LSP](https://langserver.org/)**.

> Не проходите все шаги строго по очереди — то, что можно делать параллельно, делайте параллельно. Интерактивные учебники проходите одновременно с практикой в настоящем Vim.

## Почему Vim? Сравнение с обычными редакторами (по гайду Hexlet)

Обычные редакторы (VS Code, Sublime Text, Atom, Brackets, IDE) сравнивают по характеристикам:

- **Скорость работы**
- **Возможности редактирования** — мультикурсоры, сплиты
- **Количество плагинов** под языки и инструменты
- **Интеграции** — git, терминалы и т.п.

При таком сравнении Vim выглядит «бледно»: он **самый быстрый**, но плагинов меньше, а интеграций «из коробки» почти нет. Это терминальная программа: мышь поддерживается, но работать ей неудобно (скроллинг идёт построчно, рывками). И кривая обучения у Vim **даже круче, чем у Emacs**.

**Но!** Если слепая десятипальцевая печать создана для эффективного **набора** текста — то Vim создан для **слепого десятипальцевого редактирования**. Он предлагает не «горячие клавиши + мышь», а **язык модификации текста** (см. следующий раздел).

### Vim-режим вокруг нас (доказательство популярности)

Почти в каждом редакторе самый популярный плагин — это **эмуляция Vim** (в VS Code — миллион+ установок). Но его влияние шире:

- **Gmail** — навигация в стиле Vim прямо в веб-интерфейсе
- **GitHub** — на странице репозитория нажмите `?` — откроются хоткеи в стиле Vim
- **Браузеры** — популярные плагины навигации в стиле Vim (Vimium и др.)
- **Пейджеры `less` / `more`** — навигация, портированная из Vim (`git log` и т.п. тоже)
- **Bash**: `set -o vi` — командная строка превращается в vi-режим (по умолчанию в bash, кстати, включён режим **emacs**)

### Интеграция с терминалом (ещё одно преимущество)

Vim открывается прямо во вкладках терминала, а продвинутые терминалы поддерживают **сплит-окна**. Поэтому встроенный терминал Vim особо не нужен — удобно комбинируете вкладки терминала и Vim для настроенного рабочего процесса.

## Философия Vim (почему он так работает)

Vim создан для **слепого десятипальцевого редактирования**. Вместо комбинаций клавиш, которые жмутся одновременно, здесь команды **короткие и составные, нажимаются последовательно**.

### Основные режимы

- **Normal (обычный)** — режим по умолчанию. Набор текста невозможен, зато работают команды перемещения и модификации. Все команды — это «язык».
- **Insert (вставка)** — для набора текста. Вход: `i`, `a`, `o` и др. Выход: `Esc` (или `Ctrl+c`).
- **Visual (выделение/визуальный)** — выделение текста (как normal, но для выделения).
- **Командная строка (`:`)** — ввод команд, например `:help`, `:w`, `:q`.

**Схема переходов между режимами** (суть Vim — научиться быстро прыгать между ними):

```
                     i, I, a, A, o, O
                 ┌────────────────────────────►
        ┌────────┴─────────┐          ┌────────┴─────────┐
        │    NORMAL (N)    │          │    INSERT (I)    │
        │  команды, навигация│◄─────────┤    набор текста  │
        │  «язык» Vim      │  Esc /    │                  │
        └───┬───────────┬──┘  Ctrl+c   └──────────────────┘
            │           │
   v / V /  │           │  :
  Ctrl+v    │           │
            ▼           ▼
   ┌────────────────┐  ┌──────────────────┐
   │  VISUAL (V)    │  │ :COMMAND (команд.│
   │  выделение     │  │  строка) :w :q   │
   │  y / d / > <   │  │ :help :%s/…      │
   └────────────────┘  └──────────────────┘
```

> Почти всё время вы живёте в **Normal**. В insert заходите только чтобы набрать текст, в visual — чтобы выделить, в `:` — чтобы выполнить команду.

### Ключевая идея: режим Normal = язык модификации

- `w` — на слово вперёд, `b` — назад, `W`/`B` — по пробелам
- `dd` — удалить строку
- `diw` — удалить слово под курсором, `daw` — удалить слово вместе с окружением (кавычки и т.п.)
- `gg` — в начало документа
- `/` — поиск по файлу
- `r` — заменить один символ (после ввода `r` ждём следующий символ)
- `u` — отмена, `Ctrl+r` — повтор

### Логика запоминания команд (ключ к успеху!)

Vim — это **язык**, а не список случайных хоткеев. Поймёте грамматику — запомните сами:

**1. Перемещение `hjkl`** — «домашняя позиция» под правой рукой: `h` влево, `l` вправо, `j` вниз, `k` вверх. Самые частые → под указательными пальцами (средний палец `j`/`k` — по вертикали, как стрелки).

**2. Команды — это английские акронимы:**
- `d` = **d**elete (удалить), `y` = **y**ank (скопировать), `p` = **p**ut (вставить)
- `c` = **c**hange (изменить), `r` = **r**eplace (заменить 1 символ), `s` = **s**ubstitute (заменить)
- `u` = **u**ndo (отмена), `w` = **w**ord (слово), `b` = **b**ack (назад), `g` = **g**o (переход)

**3. Главная формула: «глагол + объект».** Команда = действие + цель движения:
```
d w   →  delete word        (удалить слово)
y w   →  yank word          (скопировать слово)
c w   →  change word        (изменить слово)
d d   →  delete line        (удалить строку)
c $   →  change to end      (изменить до конца строки)
```
Схематично:

```
┌─────────────────────┐   ┌──────────────────────────┐
│ ГЛАГОЛ (действие)    │   │ ОБЪЕКТ (цель/движение)   │
├─────────────────────┤   ├──────────────────────────┤
│ d  = delete удалить  │   │ w  = word    слово       │
│ c  = change изменить │   │ e  = end     конец слова │
│ y  = yank   копировать │   │ $          конец строки │
│ p  = put    вставить │   │ 0          начало строки │
│ r  = replace замен.  │   │ gg / G     начало/конец  │
│ >  = сдвиг вправо    │   │ { }        предыдущий/…  │
└──────────┬──────────┘   └────────────┬─────────────┘
           │                           │
           └───────────►  d + w  =  dw  = удалить слово
                        (составные: ciw = c + inner + w)
```

Значит, выучив ~10 «глаголов» (`d y c p r s`...) и ~15 «объектов» (`w e b 0 $ gg G`...), вы автоматически получаете **сотни** команд.

**4. Строчная = «поменьше/точнее», заглавная = «побольше/сильнее»:**
- `w` — до начала слова / `W` — до слова по пробелам
- `e` — конец слова / `E` — конец слова по пробелам
- `d` — удалить / `D` — удалить до конца строки
- `o` — новая строка снизу / `O` — сверху

**5. `i` (inner) vs `a` (around):**
- `i` — **внутри** объекта (без пробелов/скобок): `ciw` = изменить слово целиком
- `a` — **вокруг** (включая окружение): `daw` = удалить слово вместе с кавычками
- `%` — парная скобка: `d%` = удалить всё внутри скобок

Наглядная разница границ захвата:

```
       ╔══════════════════════════╗  ← a (around) захватывает вместе
       ║        " привет "        ║    с кавычками и пробелами
       ║   ┌──────────────┐       ║
       ║   │    привет    │       ║  ← i (inner) — только "мясо"
       ║   └──────────────┘       ║    без кавычек
       ╚══════════════════════════╝

   daw / yaw / caw  →  удалить/скопировать/изменить "привет" вместе с кавычками
   diw / yiw / ciw  →  только само слово  привет
```

### Клавиатура и «Leader»

- Перемещение — клавиши **`hjkl`** (впоследствии привыкаете и везде так ходите).
- Клавиша **Leader** — база большинства пользовательских комбинаций. Обычно сейчас это **пробел** (`<Space>`), в конфигах — `<Leader>`.
- Если раскладка **не QWERTY** — клавиатура «поедет», пользоваться будет больно.

### Буферы — второе преимущество

В Vim **любой** фрагмент редактора (файл, терминал, дерево файлов, окно ошибок) — это просто текстовый буфер. Один способ взаимодействия везде: поиск `/`, перемещение `hjkl`, копирование, закрытие. Буферов может быть больше, чем места на экране — они перекрывают друг друга.

**Схема «буфер vs окно vs вкладка»** — три независимых уровня:

```
 УРОВЕНЬ 1: БУФЕРЫ (buffers) — сами файлы, живут в памяти
   ┌────────────────────────────────────────────┐
   │  buf1  buf2  buf3  buf4  buf5   (сколько    │
   │         (любое число, виден только один)     │
   └────────────────────────────────────────────┘

 УРОВЕНЬ 2: ОКНА (windows) — рамки на экране, в каждой — буфер
   ┌───────────────────┐
   │  buf2 (видим)     │ ── :sp :vsp, Ctrl+w s/v, Ctrl+w w
   │  ┌───────────────┐│
   │  │ buf4 (видим)  ││
   │  └───────────────┘│
   └───────────────────┘

 УРОВЕНЬ 3: ВКЛАДКИ (tabs) — наборы окон, свои на каждую задачу
   ┌─────┬─────┬─────┐
   │ 1т  │ 2т  │ 3т  │  ── :tabnew, gt / gT
   └─────┴─────┴─────┘
```

> Переключайте **буферы** (`:bn` / `:bd`), а не открывайте файл заново. Вкладки — для группировки задач.

### Советы по здоровью рук

- Переключите **Caps Lock на Ctrl** (Ctrl активно используется).
- Для выхода из insert вместо `Esc` используйте `Ctrl+[` или собственную комбинацию (например, `jj`).
- **Обязательно** владейте слепым десятипальцевым набором — иначе Vim учить рано.

### Когда НЕ стоит учить Vim

- Вас устраивают обычные редакторы.
- Не владеете слепой печатью.
- Не готовы возиться с конфигами (хотите «просто работает») — тогда Emacs или IDE.
- Вы емаксер → тогда лучше [Spacemacs](https://github.com/syl20bnr/spacemacs).

## Полный справочник команд Vim

> Число перед командой повторяет её: `4j` — вниз на 4 строки. `:h[elp] keyword` — справка по ключевому слову.

### Общее / служебное
- `:h[elp] keyword` — справка по слову
- `:sav[eas] file` — сохранить под другим именем
- `:clo[se]` — закрыть текущую панель
- `:ter[minal]` — открыть окно терминала
- `K` — man-страница для слова под курсором

### Перемещение курсора *(как запомнить)*

**База `hjkl`** — одеколон `h`,`j`,`k`,`l`; ваши руки уже лежат на них (домашняя позиция):
- `h` — влево (`h` — самая левая буква в ряду) · `l` — вправо (`l` — правая)
- `j` — вниз (свисает вниз, как j) · `k` — вверх (торчит вверх)

**Карта навигации по «уровням»** — каждая пара клавиш отвечает за свой масштаб:

```
 УРОВЕНЬ ФАЙЛА:      <- gg ─────────────────── G ->   (g)g = самый верх / G = низ

 УРОВЕНЬ ЭКРАНА:      H ────────── M ────────── L      (High / Middle / Low)

 УРОВЕНЬ СТРОКИ:      0 ─── ^ ──────── $               (начало / 1-й символ / конец)
                          b ◄─── w  (слова вперёд/назад)

 УРОВЕНЬ СЛОВА:  F/x  t/x  ──► слово  ◄──  B  b       (f=find, t=to, b=back, w=word)

 УРОВЕНЬ СИМВОЛА:        h ◄──► l
```

Плюс **вертикаль**: `j` (вниз) и `k` (вверх) — движение по строкам; `}`/`{` — по абзацам; `Ctrl+f/b` — по страницам.

| `e` `E` | вперёд на конец слова | до **e**nd (конца) слова |
| `b` `B` | назад на слово / по пробелам | **b**ack = назад |

| `gd` `gD` | к локальному/глобальному объявлению | g + **d**efinition |

### Режим вставки *(как запомнить)*
Основное правило — **чёт/нечет**: `i` вставляет перед курсором, `a` — после; строчная — «здесь», заглавная — «наружу к краю строки»:
- `i` — **i**nsert перед курсором · `I` — вставляет в начало строки
- `a` — **a**ppend (=add) после курсора · `A` — в конец строки
- `o` — новая строка **o**ткрывается снизу · `O` — сверху
- `ea` — «после `e`nd слова» = вставить в конец слова
- `Ctrl+h` — удалить символ слева = «как Backspace» · `Ctrl+w` — слово слева
- `Ctrl+t` `Ctrl+d` — отступ вправо/влево (**t**ab вправо, **d**eindent влево)
- `Ctrl+n` `Ctrl+p` — автодополнение (**n**ext / **p**revious совпадение)
- `Ctrl+r x` — вставить содержимое регистра `x` (`r` = **r**egister)
- `Ctrl+o x` — временно сделать команду normal-режима `x` (`o` = разовый выход)
- `Esc` / `Ctrl+c` — выход из вставки

### Редактирование *(глагол + объект)*
**Главная формула результата:** `c` (change) + объект — «изменить»; `d` (delete) — «удалить»; `y` (yank) — «скопировать». Объект = `w` слово / `$` конец / `i` внутренность:
- `r` — заменить **r**eplace один символ · `R` — заменять подряд до Esc
- `s` — **s**ubstitute (заменить) символ на текст · `S` — заменить строку
- `cc` — изменить строку (`c` + `c` = вся строка) · `C`/`c$` — до конца строки
- `ciw` — изменить **inner word** (всё слово) · `cw`/`ce` — до конца слова
- `J` — **J**oin (склеить) строки · `gJ` — без пробела
- `x` — «вырезать» символ (как икс = удалить) · `xp` — переставить 2 буквы
- `u` — **u**ndo отменить · `U` — откатить строку · `Ctrl+r` — redo повторить
- `.` — повторить последнюю команду (точка = «ещё раз то же») 

### Выделение (Visual) *(v = visual)*
- `v` — **V**isual режим · `V` — построчный · `Ctrl+v` — блочный
- `o` — прыгнуть на другой конец выделения · `O` — другой угол блока
- `aw` — **a**round word (слово) · `ab`/`ib` — блок в `()` · `aB`/`iB` — в `{}` · `at`/`it` — в `<>`
- В visual: `y` — копировать · `d` — удалить · `>`/`<` — отступ · `~` — регистр · `u`/`U` — нижний/верхний
- `Esc` / `Ctrl+c` — выход

### Регистры
- `:reg[isters]` — показать регистры
- `"xy` — в регистр `x`; `"xp` — вставить из регистра `x`
- `"+y` / `"+p` — системный буфер обмена
- Специальные: `0` посл. копия; `"` безымянный; `%` имя файла; `#` альтерн. файл; `*`/`+` буфер X11; `/` посл. поиск; `:` посл. команда; `.` посл. вставка; `-` малое удаление; `=` выражение; `_` чёрная дыра
- Регистры сохраняются в `~/.viminfo`

### Метки
- `:marks` — список меток; `ma` — метка `a`; `` `a `` — перейти к метке; `y\`a` — копировать до метки
- `` `0 `` — место последнего закрытия; `` `" `` — место закрытия файла; `` `. `` — место последнего изменения; `` `` `` — перед последним переходом
- `:ju[mps]` — список переходов; `Ctrl+i`/`Ctrl+o` — новый/старый переход
- `:changes` — список изменений; `g,`/`g;` — новое/старое изменение
- `Ctrl+]` — перейти к тегу под курсором
- Про `'` (апостроф) — начало строки метки

### Макросы
- `qa` — записать макрос `a`; `q` — остановить; `@a` — выполнить; `@@` — повторить последний

### Вырезать и вставить *(формула `y`/`d`/`p`)*
**Копия = `y` (yank), удаление = `d` (delete), вставка = `p` (put).** Загружаешь «объект» так же, как для `c`hange:
- `yy` — копировать строку (двойная = строка) · `2yy` — 2 строки
- `yw` — слово · `yiw` — слово под курсором (inner) · `yaw` — слово + окружение (around)
- `y$`/`Y` — до конца строки
- `dd` — удалить строку · `2dd` — 2 строки · `dw` — слово · `diw`/`daw` — inner/around
- `d$`/`D` — до конца строки · `x` — один символ
- `p` — вставить **p**ut после курсора · `P` — перед
- `gp`/`gP` — вставить и встать после текста
- Диапазоны: `:3,5d` — строки 3–5; `:.,$d` — с текущей до конца; `:g/pattern/d` — удалить строки с паттерном; `:g!/pattern/d` — без паттерна

### Отступы
- `>>` `<<` — отступ строки вправо/влево (стрелки = сдвиг текста)
- `>%` / `<%` — отступ блока в `()`/`{}` (парный символ `%`)
- `>ib` / `>at` — отступ внутреннего блока `()` / блока `<>`
- `3==` — выровнять 3 строки · `=%` — блок · `=iB` — блок в `{}` · `gg=G` — весь файл
- `]p` — вставить с выравниванием отступа

### Выход и сохранение *(запомните 4 базовых)*
- `:w` — **w**rite (сохранить) · `:w !sudo tee %` — сохранить с sudo
- `:q` — **q**uit (выйти) · `:q!` — выйти без сохранения
- `:wq` / `:x` / `ZZ` — сохранить **и** выйти (`w` + `q`)
- `:wqa` — сохранить и выйти во всех вкладках/буферах (+ `a` = **a**ll)

### Поиск и замена
- `/pattern` — поиск вперёд · `?pattern` — назад (`/` вниз = вперёд, `?` вверх = назад)
- `n` — повторить **n**ext · `N` — в обратную сторону
- `:%s/old/new/g` — **s**ubstitute во всём файле (`g` = глобально) · `gc` — с подтверждением
- `:noh[lsearch]` — убрать подсветку поиска

### Поиск в нескольких файлах
- `:vim[grep] /pattern/ **/*` — поиск по файлам
- `:cn[ext]` / `:cp[revious]` — следующее/предыдущее совпадение
- `:cope[n]` — окно результатов · `:ccl[ose]` — закрыть

### Вкладки *(tab = вкладка)*
- `:tabnew file` / `Ctrl+w T` — новая вкладка
- `gt` — следующая вкладка (g + **t**ab) · `gT` — предыдущая · `<число>gt` — по номеру
- `:tabm[ove] #` — переместить · `:tabc[lose]` — закрыть · `:tabo[nly]` — оставить одну
- `:tabdo command` — выполнить во всех вкладках

### Несколько файлов / окна *(всё начинается с `Ctrl+w` = window)*
- `Ctrl+w s` — сплит по **s**горизонтали · `Ctrl+w v` — **v**ертикально
- `Ctrl+w h/l/j/k` — перейти влево/вправо/вниз/вверх (стрелки `hjkl`!)
- `Ctrl+w H/L/J/K` — перенести окно в край
- `Ctrl+w w` — переключение между окнами · `Ctrl+w q` — закрыть · `Ctrl+w x` — поменять местами · `Ctrl+w =` — равные размеры
- `:e[dit] file` — новый буфер · `:bn[ext]`/`:bp[revious]` — след./пред. буфер · `:bd[elete]` — удалить · `:ls` — список
- `:sp[lit] file` / `:vs[plit] file` — файл в сплите (гориз./верт.)
- `:vert[ical] ba[ll]` / `:tab ba[ll]` — открыть все буферы

### Свёртки и сравнение файлов
- `zf` — свёртка; `zd` — удалить; `za` — переключить; `zo` — раскрыть; `zc` — свернуть; `zr`/`zm` — все на уровень; `zi` — переключить все (заглавные — по всем уровням)
- `]c` / `[c` — следующее/предыдущее отличие
- `do`/`:diffg[et]` — взять отличие; `dp`/`:diffpu[t]` — вставить отличие
- `:diffthis` `:dif[fupdate]` `:diffo[ff]` — режим сравнения
- `vimdiff file1 file2` — запуск сравнения из терминала (можно как git difftool)
